## 데이터 형식이란

**데이터 형식(Data Format)**은 데이터를 **저장하거나 주고받을 때 어떤 모양으로 적을지 정한 규칙**이다.
같은 정보라도 형식에 맞춰 적어야, 받는 쪽 프로그램이 규칙대로 읽어낼 수 있다.

예를 들어 "이름은 민수, 나이는 17"이라는 정보를 형식별로 적으면 이렇게 된다.

| 형식 | 적은 모양 |
| --- | --- |
| JSON | `{"name": "민수", "age": 17}` |
| CSV | `name,age` 다음 줄에 `민수,17` |
| YAML | `name: 민수` 다음 줄에 `age: 17` |

## 헷갈리기 쉬운 개념 비교

| 개념 | 한 줄 설명 | 예 |
| --- | --- | --- |
| **데이터 형식** | 내용을 **어떤 구조로** 적을지 정한 규칙 | JSON, CSV, YAML, XML |
| **확장자** | 파일 **이름 끝**에 붙인 꼬리표. 형식을 알려주는 힌트 | `.json`, `.csv`, `.yml` |
| **MIME 타입** | 인터넷에서 데이터를 보낼 때 **헤더로** 알려주는 형식 이름 | `application/json`, `text/csv` |
| **문자 인코딩** | 글자를 **어떤 바이트로** 바꿀지 정한 규칙 | UTF-8, CP949 |
| **자료형** | 프로그램 **안에서** 값 하나가 어떤 종류인지 | 정수, 문자열, 리스트 |

### 데이터 형식과 확장자

확장자는 **이름표**일 뿐이고, 형식은 **안에 든 내용**이 정한다.

- `data.json`을 `data.txt`로 이름만 바꿔도 내용은 여전히 JSON이다.
- 아무 글이나 적고 이름을 `data.json`으로 붙인다고 JSON이 되지는 않는다. 읽으려고 하면 오류가 난다.
- 확장자는 운영체제가 어떤 프로그램으로 열지, 편집기가 문법 색칠을 어떻게 할지 정할 때 쓰인다.

### 확장자와 MIME 타입

HTTP 응답에는 파일 이름이 없다. 그래서 확장자 대신 `Content-Type: application/json` 같은 **헤더**로 형식을 알려준다.
같은 역할을 파일에서는 확장자가, 인터넷 통신에서는 MIME 타입이 한다고 보면 된다. ([[http와-https#자주-쓰는-헤더|HTTP 헤더]])

### 데이터 형식과 문자 인코딩

둘은 **층이 다르다.** 형식은 "어떤 구조로 적을까", 인코딩은 "그 글자를 어떤 바이트로 바꿀까"다.

- 같은 JSON이라도 UTF-8로 저장할 수도 있고 CP949로 저장할 수도 있다.
- 그래서 형식은 맞는데 한글이 깨지는 경우가 생긴다. 이건 형식이 아니라 인코딩 문제다. ([[인코딩과-디코딩]], [[문자-인코딩-utf8-cp949]])

### 데이터 형식과 자료형

자료형은 **프로그램 안**에서 값을 다루는 방식이고, 데이터 형식은 **프로그램 밖**으로 내보낼 때의 모양이다.

- Python의 딕셔너리(`dict`)를 파일에 저장하려면 JSON 같은 형식으로 **바꿔서(직렬화)** 적어야 한다.
- 반대로 JSON을 읽어서 다시 딕셔너리로 만드는 것을 **역직렬화**라고 한다.

### 텍스트 형식과 바이너리 형식

| 구분 | 특징 | 예 |
| --- | --- | --- |
| **텍스트 형식** | 메모장으로 열어도 사람이 읽을 수 있다 | JSON, CSV, YAML, XML, HTML |
| **바이너리 형식** | 바이트 그대로 저장해서 사람이 읽기 어렵지만, 크기가 작고 빠르다 | PNG, ZIP, SQLite DB 파일 |

## 대표적인 데이터 형식

| 형식 | 특징 | 주로 쓰는 곳 |
| --- | --- | --- |
| **JSON** | 객체와 배열로 구조를 표현. 거의 모든 언어가 지원 | 웹 API 응답, 설정 파일 |
| **CSV** | 쉼표로 칸을 나눈 표. 엑셀에서 바로 열림 | 표 형태 데이터 ([[folium-지도]]의 지점 목록) |
| **YAML** | 들여쓰기로 구조를 표현. 사람이 쓰기 편함 | 설정 파일, 이 사이트의 `tags.yml`과 문서 맨 위 속성 |
| **XML** | 태그로 구조를 표현. HTML과 모양이 비슷 | 오래된 API, 문서 형식, 안드로이드 레이아웃 |
