## 캐시 (Cache)

데이터나 값을 **미리 복사해 놓는 임시 장소**다.

원래 데이터에 접근하는 시간이 오래 걸리는 경우나,
값을 다시 계산하는 시간을 절약하고 싶은 경우에 사용한다.

최근에 사용했거나 인접한 데이터를 다시 쓸 때 유용하다.

| 계층 | 설명 |
| --- | --- |
| **레지스터(Registers)** | CPU 내부의 가장 빠른 메모리 |
| **캐시(Cache)** | SRAM을 사용하며 CPU와 메모리 사이를 중재한다 |
| **메모리(Memory)** | DRAM 기반의 주기억장치 |
| **디스크(Disk)** | 대용량 데이터를 저장하는 보조기억장치 |

## 캐싱 (Caching)

데이터나 연산 결과를 임시 저장소(캐시)에 복사해 두고,
동일한 요청이 올 때 원래 위치보다 **더 빠르게 데이터를 제공하는 기술**이다.

- **Cache hit (적중):** 요청한 데이터가 캐시에 있으면, 즉시 초고속으로 반환한다.
- **Cache miss (실패):** 데이터가 캐시에 없으면 디스크 등 원본 위치에서 데이터를 가져와 캐시에 저장한 후 반환한다.

### 우리 주변의 캐싱 예시

- **웹 브라우저:** 방문한 사이트의 로고나 이미지를 내 컴퓨터에 저장해 두고, 재방문 시 즉시 띄운다.
- **유튜브 영상:** 인기 있는 영상은 전 세계 사용자와 가까운 서버(CDN)에 미리 복사해 두어 버퍼링을 줄인다.
- **스마트폰 앱:** 자주 쓰는 프로필 사진이나 피드 데이터를 기기에 임시 저장하여 매번 새로 다운로드하지 않도록 한다.
