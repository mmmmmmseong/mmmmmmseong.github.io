## CSV란

**CSV(Comma-Separated Values)**는 **쉼표로 칸을, 줄바꿈으로 행을 나눈** 표 형식이다.
엑셀 같은 표 프로그램에서 바로 열 수 있어서, 표 형태의 데이터를 주고받을 때 가장 흔하게 쓰인다.
오래전부터 쓰이던 형식을 2005년 RFC 4180이 정리했지만, 프로그램마다 조금씩 다르게 쓰는 경우가 많다.

| 항목 | 값 |
| --- | --- |
| 확장자 | `.csv` |
| MIME 타입 | `text/csv` |

## 기본 구조

```csv
연번,지점,코스
1,정문,A
2,"약수터, 쉼터",B
3,"이른바 ""정상""",A
```

- 첫 줄은 보통 **열 이름(헤더)**이다.
- 칸 안에 **쉼표나 줄바꿈이 있으면** 그 칸을 큰따옴표로 감싼다.
- 칸 안의 큰따옴표는 **두 번(`""`)** 적는다.

## JSON과 비교

| 구분 | CSV | [[json|JSON]] |
| --- | --- | --- |
| 구조 | 행과 열로 된 **평평한 표** | 객체·배열을 **겹쳐 넣을 수 있음** |
| 자료형 | 없음. 모든 칸이 **글자** | 문자열, 숫자, 불리언, null 구분 |
| 크기 | 열 이름을 한 번만 적어서 작음 | 행마다 이름을 반복해서 큼 |
| 잘 맞는 것 | 엑셀로 보고 고칠 표 데이터 | 구조가 복잡한 데이터, API |

CSV에는 자료형이 없어서, `17`도 읽어 들이면 **글자 "17"**이다. 숫자로 계산하려면 직접 바꿔야 한다.

## 엑셀과 함께 쓸 때

- **BOM:** 엑셀에서 "CSV UTF-8"로 저장하면 파일 맨 앞에 BOM이 붙어서, 첫 열 이름이 `﻿연번`처럼 읽힐 수 있다. 파이썬에서는 `encoding="utf-8-sig"`로 읽으면 된다. ([[folium-지도]], [[문자-인코딩-utf8-cp949]])
- **한글 깨짐:** BOM 없는 UTF-8 CSV를 엑셀에서 더블클릭으로 열면 한글이 깨질 수 있다. "데이터 가져오기"로 인코딩을 지정해서 열면 된다.
- **앞자리 0 사라짐:** `010`, `00123` 같은 값을 엑셀이 숫자로 바꿔 `10`, `123`이 된다. 전화번호, 학번 같은 값은 열 형식을 텍스트로 두자.
- **구분자가 다른 경우:** 쉼표 대신 탭으로 나눈 **TSV**, 세미콜론으로 나눈 파일도 있다. 열리긴 하는데 한 칸에 다 몰려 보이면 구분자를 확인해보자.

## 파이썬에서 읽고 쓰기

`split(",")`으로 직접 나누면 따옴표 안의 쉼표에서 칸이 잘못 나뉜다. 표준 라이브러리 `csv` 모듈을 쓰는 것이 좋다.

```python
import csv

with open("PathMap.csv", encoding="utf-8-sig", newline="") as f:
    for row in csv.DictReader(f):      # 각 행을 {"연번": "1", "지점": "정문", ...}로
        print(row["지점"])

with open("out.csv", "w", encoding="utf-8-sig", newline="") as f:
    writer = csv.writer(f)
    writer.writerow(["연번", "지점"])
    writer.writerow([1, "약수터, 쉼터"])   # 쉼표가 있으면 알아서 따옴표로 감싼다
```

- `newline=""`을 주지 않으면 Windows에서 행 사이에 빈 줄이 생길 수 있다.
- 데이터 분석을 한다면 `pandas.read_csv()`가 편하다.

## 보안 관점: CSV 인젝션

칸 값이 `=`, `+`, `-`, `@`로 시작하면 엑셀이 **수식으로 실행**할 수 있다.
사용자가 입력한 값을 CSV로 내보내는 기능이 있다면, 이런 문자로 시작하는 값 앞에 `'`를 붙이는 식으로 막아두자.
