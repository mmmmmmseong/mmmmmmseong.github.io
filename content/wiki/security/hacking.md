이 폴더에는 **공격 기법과 실습 기록**을 모아둔다.
공격이 어떻게 이루어지는지 알아야 제대로 막을 수 있으므로, 각 문서에는 공격 원리와 함께 막는 법도 정리한다.

방어와 보안 설계는 [[defense|방어]]에, 워게임·CTF 풀이 기록은 [[wargame|워게임]]에 따로 둔다.

## 실습 범위

해킹 실습은 **허락된 대상에서만** 한다.

- 직접 만든 서비스나 로컬 환경
- 워게임, CTF처럼 공격이 허락된 문제
- 분석이 허락된 앱

허락 없이 다른 사람의 시스템에 접근하는 것은 정보통신망법 위반이다. 자세한 내용은 [[정보통신망법|해킹 공부와 정보통신망법]]에 정리했다.

## 공부하는 분야

해킹 분야 전체를 나눈 것이 아니라, **지금까지 공부했거나 공부하고 있는 분야**만 적었다. 새로 공부하는 분야가 생기면 한 줄씩 추가한다.

| 분야 | 다루는 내용 |
| --- | --- |
| 웹 | 정찰, 인젝션, 권한 검증 누락 등 웹 서비스 취약점 |
| 시스템·리눅스 | 리눅스 명령어, 권한, 워게임 풀이 |
| 리버싱·앱 분석 | APK 구조, 디컴파일, 코드 분석 |
| AI | 프롬프트 인젝션 등 LLM을 노리는 공격 |
