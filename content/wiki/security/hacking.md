이 폴더에는 **공격 기법과 실습 기록**을 모아둔다.
공격이 어떻게 이루어지는지 알아야 제대로 막을 수 있으므로, 각 문서에는 공격 원리와 함께 막는 법도 정리한다.

방어 설계나 개념 위주의 내용은 상위 분류인 보안(security)에 둔다.

## 실습 범위

해킹 실습은 **허락된 대상에서만** 한다.

- 직접 만든 서비스나 로컬 환경
- 워게임, CTF처럼 공격이 허락된 문제
- 분석이 허락된 앱

허락 없이 다른 사람의 시스템에 접근하는 것은 정보통신망법 위반이다.
워게임 중에는 풀이나 비밀번호 공개를 금지하는 곳도 있으니, 풀이를 올리기 전에 규칙을 확인하도록 하자.

## 분야

| 분야 | 다루는 내용 |
| --- | --- |
| 웹 | 정찰, 인젝션, 권한 검증 누락 등 웹 서비스 취약점 |
| 시스템·리눅스 | 리눅스 명령어, 권한, 워게임 풀이 |
| 리버싱·앱 분석 | APK 구조, 디컴파일, 코드 분석 |
| AI | 프롬프트 인젝션 등 LLM을 노리는 공격 |

## 풀이 기록 틀

워게임이나 CTF 풀이는 같은 틀로 남겨두면 나중에 다시 보기 좋다.

```text
문제 개요 → 처음 접근 → 막힌 부분 → 풀이 → 배운 점 (+ 막는 법)
```
