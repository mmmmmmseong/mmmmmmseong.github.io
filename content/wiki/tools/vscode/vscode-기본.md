## 화면 구성

| 위치 | 이름 | 하는 일 |
| --- | --- | --- |
| 맨 왼쪽 아이콘 줄 | 작업 표시줄 (Activity Bar) | 탐색기, 검색, 소스 제어, 실행/디버그, 확장 전환 |
| 그 옆 | 사이드바 | 고른 기능의 내용 (파일 목록 등) |
| 가운데 | 편집기 | 파일 편집. 탭으로 여러 파일, 좌우로 나눠 보기 가능 |
| 아래 | 패널 | 터미널, 문제(오류 목록), 출력, 디버그 콘솔 |
| 맨 아래 줄 | 상태 표시줄 | 현재 브랜치, 오류 수, Python 버전, 인코딩, 줄 끝 문자 |

상태 표시줄은 작아 보여도 중요하다. **브랜치 이름, 선택된 Python 인터프리터, 파일 인코딩**을 여기서 보고 바꾼다.

## 파일이 아니라 폴더를 연다

프로젝트는 항상 **파일 → 폴더 열기**로 폴더째 연다. 파일 하나만 열면 다음 기능이 제대로 동작하지 않는다.

- 다른 파일의 함수로 이동하기, 자동 완성
- Git 소스 제어
- 프로젝트별 설정(`.vscode/settings.json`)과 디버그 설정(`.vscode/launch.json`)

터미널에서 `code .`을 입력하면 현재 폴더가 바로 열린다.

### 작업 영역 신뢰

처음 여는 폴더에서는 "이 폴더의 작성자를 신뢰하는가?"라고 묻는다.
신뢰하지 않으면 **제한 모드**로 열려서, 폴더 안의 설정이나 작업(task)이 자동으로 코드를 실행하지 못한다.
인터넷에서 받은 모르는 코드는 제한 모드로 먼저 살펴보는 게 안전하다.

## 꼭 알아야 할 단축키

Windows 기준이다. Mac은 대부분 `Ctrl` 대신 `Cmd`를 쓴다.

### 찾기와 이동

| 단축키 | 하는 일 |
| --- | --- |
| `Ctrl+Shift+P` | **명령 팔레트**. 메뉴에 없는 기능도 이름으로 찾아 실행 |
| `Ctrl+P` | 파일 이름으로 빠르게 열기. `@`를 붙이면 함수 목록, `:`를 붙이면 줄 번호로 이동 |
| `Ctrl+Shift+F` | 프로젝트 전체에서 검색·바꾸기 |
| `F12` | 정의로 이동 (함수가 만들어진 곳) |
| `Shift+F12` | 이 함수를 쓰는 곳 모두 보기 |
| `Alt+←` | 이전 위치로 돌아가기 |
| `Ctrl+Shift+M` | 문제(오류·경고) 목록 |

### 편집

| 단축키 | 하는 일 |
| --- | --- |
| `Alt+↑` / `Alt+↓` | 현재 줄을 위·아래로 옮기기 |
| `Shift+Alt+↓` | 현재 줄 복사해서 아래에 붙이기 |
| `Ctrl+/` | 주석 켜고 끄기 |
| `Ctrl+D` | 같은 단어를 하나씩 더 선택 (여러 곳 동시에 고치기) |
| `Alt+클릭` | 커서 여러 개 만들기 |
| `F2` | 변수·함수 이름을 쓰는 곳까지 한 번에 바꾸기 |
| `Shift+Alt+F` | 문서 정렬(포맷) |

### 화면

| 단축키 | 하는 일 |
| --- | --- |
| `` Ctrl+` `` | 터미널 열고 닫기 |
| `Ctrl+B` | 사이드바 숨기기 |
| `Ctrl+\` | 편집기 좌우로 나누기 |
| `Ctrl+,` | 설정 열기 |

## 설정

설정은 두 단계가 있다.

| 종류 | 적용 범위 | 저장 위치 |
| --- | --- | --- |
| **사용자 설정** | 내 VS Code 전체 | 내 PC (설정 동기화 대상) |
| **작업 영역 설정** | 지금 연 폴더만 | 그 폴더의 `.vscode/settings.json` |

같은 설정이 둘 다 있으면 **작업 영역 설정이 이긴다.** 프로젝트마다 다른 값(들여쓰기, Python 경로 등)은 작업 영역 설정에 둔다.

`Ctrl+,`로 여는 설정 화면은 검색해서 고르는 방식이다. 오른쪽 위 아이콘으로 `settings.json`을 직접 열어 고칠 수도 있다.

### 바꿔두면 편한 설정

```jsonc
{
  "files.autoSave": "afterDelay",        // 잠깐 멈추면 자동 저장
  "editor.formatOnSave": true,           // 저장할 때 자동 정렬
  "editor.minimap.enabled": false,       // 오른쪽 미니맵 끄기
  "files.trimTrailingWhitespace": true,  // 줄 끝 공백 지우기
  "workbench.iconTheme": "material-icon-theme"  // 파일 아이콘 (Material Icon Theme 확장)
}
```

### 한국어로 바꾸기

한국어 언어 팩 확장을 설치하고, 명령 팔레트에서 `Configure Display Language` → `한국어`를 고른 뒤 다시 시작한다.
명령어 이름은 영어로 검색해도 찾아진다.
