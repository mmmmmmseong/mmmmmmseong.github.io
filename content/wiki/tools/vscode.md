**Visual Studio Code(VS Code)**는 Microsoft가 만든 무료 코드 편집기다. 가볍게 시작하지만, 확장을 설치하면 Python·Java·웹·C/C++까지 대부분의 개발을 한 프로그램에서 할 수 있다.
내 프로젝트도 거의 다 VS Code로 만들었다.

## 읽는 순서

1. **VS Code 기본:** 화면 구성, 꼭 알아야 할 단축키, 설정
2. **개발 환경:** 내가 쓰는 언어별(Python, Java, 웹, C/C++, WSL) 설정
3. **Git 연동:** 소스 제어 화면으로 커밋·push·충돌 해결
4. **추천 확장:** 실제로 쓰고 있는 확장 중 쓸모 있는 것들
5. **설정 동기화:** 여러 PC에서 같은 환경 쓰기

아래 **하위 문서**에서 바로 펼쳐 읽거나, 각 문서를 따로 열어 볼 수 있다.

## 한 장 요약

| 하고 싶은 것 | 방법 |
| --- | --- |
| 모든 기능 찾기 | `Ctrl+Shift+P` (명령 팔레트) |
| 파일 바로 열기 | `Ctrl+P` |
| 터미널 열기 | `` Ctrl+` `` |
| 설정 열기 | `Ctrl+,` |
| Python 인터프리터 고르기 | 명령 팔레트 → `Python: Select Interpreter` |
| 커밋하기 | `Ctrl+Shift+G` → 메시지 입력 → `Ctrl+Enter` |
