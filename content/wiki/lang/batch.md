## 배치파일이란

**배치파일**은 Windows 명령 프롬프트(`cmd.exe`)에서 실행할 명령들을 **순서대로 적어둔 텍스트 파일**이다. 확장자는 `.bat` 또는 `.cmd`를 쓴다.
더블클릭하면 `cmd.exe`가 파일을 위에서부터 한 줄씩 읽어 실행한다.

"프로그램 몇 개 켜기", "폴더 정리하기", "네트워크 설정 초기화하기"처럼 **매번 손으로 하는 반복 작업**을 파일 하나로 묶어둘 때 쓴다.
MS-DOS 시절부터 이어져 온 방식이라 모든 Windows에 기본으로 들어 있고, 따로 설치할 것이 없다는 것이 가장 큰 장점이다.

| 항목 | 내용 |
| --- | --- |
| 확장자 | `.bat`, `.cmd` (지금은 거의 같다. `.cmd`는 일부 명령의 오류 코드 처리가 조금 다르다) |
| 실행하는 프로그램 | `cmd.exe` (명령 프롬프트) |
| 다른 선택지 | 복잡한 작업은 PowerShell(`.ps1`)이나 [[python|Python]]이 더 편하다 |

## 기본 구조

```bat
@echo off
rem 이 줄은 주석이다
echo 안녕하세요
pause
```

| 명령 | 하는 일 |
| --- | --- |
| `@echo off` | 실행하는 명령 자체를 화면에 찍지 않는다. 거의 모든 배치파일의 첫 줄 |
| `rem` 또는 `::` | 주석 |
| `echo 글자` | 글자를 화면에 출력. 빈 줄은 `echo.` |
| `pause` | "계속하려면 아무 키나 누르십시오"를 띄우고 기다린다. 없으면 창이 바로 닫혀서 결과를 못 본다 |

## 자주 쓰는 명령

| 명령 | 예 | 하는 일 |
| --- | --- | --- |
| `start` | `start "" "C:\경로\프로그램.exe"` | 프로그램·파일·주소를 연다. 기다리려면 `/wait` |
| `timeout` | `timeout /t 3 /nobreak >nul` | 3초 기다리기 |
| `mkdir` | `mkdir "새 폴더"` | 폴더 만들기 (중간 폴더까지 한 번에) |
| `copy`, `move`, `del` | `copy a.txt b.txt` | 파일 복사·이동·삭제 |
| `cd /d` | `cd /d "D:\작업"` | 작업 폴더 바꾸기. `/d`가 있어야 드라이브까지 바뀐다 |
| `taskkill` | `taskkill /im notepad.exe /f` | 프로그램 강제 종료 |
| `tasklist` | `tasklist` | 실행 중인 프로그램 목록 |
| `exit /b` | `exit /b 1` | 배치 종료 (숫자는 오류 코드) |

명령 뒤의 `>nul`은 출력을 버린다는 뜻이고, `2>&1`을 붙이면 오류 메시지까지 버린다.

## 변수

```bat
set name=민수
echo %name%

set /a count=3+4
set /p answer=이름을 입력하세요: 
```

- `set 이름=값`으로 만들고 `%이름%`으로 쓴다. **`=` 앞뒤에 공백을 넣으면 안 된다.** 공백까지 이름과 값에 포함된다.
- `set /a`는 계산, `set /p`는 사용자 입력을 받는다.

### 미리 정해진 변수

| 변수 | 값 |
| --- | --- |
| `%USERPROFILE%` | 사용자 폴더 (`C:\Users\이름`) |
| `%TEMP%` | 임시 폴더 |
| `%ProgramFiles%` | `C:\Program Files` |
| `%~dp0` | **이 배치파일이 있는 폴더** (끝에 `\` 포함) |
| `%1`, `%2` … | 배치파일에 넘긴 인자 |
| `%ERRORLEVEL%` | 바로 앞 명령의 결과 코드 (0이면 보통 성공) |

`%~dp0`은 특히 자주 쓴다. 배치파일을 다른 폴더에서 실행해도 **배치파일 옆의 파일**을 찾을 수 있다.

## 조건과 이동

```bat
if exist "설정.txt" echo 설정 파일이 있다
if not exist "로그\" mkdir "로그"
if "%answer%"=="y" echo 예를 골랐다

ping google.com -n 1 >nul
if errorlevel 1 goto :offline
echo 인터넷 연결됨
goto :eof

:offline
echo 인터넷 연결 안 됨
```

- `if exist`로 파일·폴더가 있는지 확인한다. 폴더만 확인하려면 경로 끝에 `\`를 붙인다.
- `if errorlevel 1`은 "결과 코드가 **1 이상**이면"이라는 뜻이다. 보통 "앞 명령이 실패했으면"으로 쓴다.
- `goto :라벨`로 `:라벨` 줄로 건너뛴다. `goto :eof`는 파일 끝으로 가서 끝낸다.
- 문자열 비교는 양쪽을 따옴표로 감싸야 값이 비었을 때 오류가 나지 않는다.

## 반복

```bat
for %%f in (*.txt) do echo %%f
for /l %%i in (1,1,5) do echo %%i번째
```

배치파일 안에서는 `%%f`처럼 `%`를 **두 번** 쓴다. 명령 프롬프트에 직접 칠 때는 `%f` 하나다.

## 자주 빠지는 함정

### 경로에 공백이 있으면 따옴표

`C:\Program Files\...`처럼 공백이 있는 경로는 반드시 `"`로 감싸야 한다. 습관적으로 모든 경로를 감싸두는 것이 좋다.

### start의 첫 따옴표는 창 제목

`start "C:\경로\프로그램.exe"`라고 쓰면 경로가 **창 제목**으로 읽혀서 프로그램이 안 열린다.
항상 `start "" "경로"`처럼 빈 제목을 먼저 넣자.

### %는 두 번

배치파일 안에서 `%`는 변수 기호라서, 글자 그대로 쓰려면 `%%`로 적어야 한다. URL의 `%20` 같은 값이 사라지는 이유가 이것이다.

### 특수문자는 ^로

`&`, `<`, `>`, `^`와 파이프 기호는 명령을 잇거나 출력을 보내는 기호라서, `echo`로 출력하려면 앞에 `^`를 붙여야 한다.

### 괄호 블록 안의 변수

```bat
set n=1
if exist a.txt (
    set n=2
    echo %n%
)
```

위 코드는 `2`가 아니라 `1`을 출력한다. 괄호 블록은 **실행하기 전에 한꺼번에 읽어서** 그때 `%n%`을 값으로 바꿔버리기 때문이다.
블록 안에서 바뀐 값을 쓰려면 `setlocal EnableDelayedExpansion`을 켜고 `!n!`으로 쓰거나, 괄호 대신 `goto`로 흐름을 나누면 된다.

경로에 `(1)` 같은 괄호가 들어 있어도 괄호 블록이 깨질 수 있다. [[batcreat|batCreat]]이 조건을 괄호 대신 `goto` 라벨로 만드는 이유다.

### 한글이 깨진다

명령 프롬프트는 기본으로 **CP949**(한국어 Windows)로 글자를 읽는다. 메모장의 기본 저장 형식인 UTF-8로 저장하면 한글이 깨진다.

- 메모장에서 "다른 이름으로 저장" → 인코딩을 **ANSI**로 저장하거나,
- UTF-8로 저장했다면 `@echo off` 다음 줄에 `chcp 65001 >nul`을 넣으면 된다.

자세한 원리는 [[문자-인코딩-utf8-cp949]]에 정리했다.

## 관리자 권한

`C:\Windows` 아래를 고치거나 일부 네트워크 설정을 바꾸는 명령은 관리자 권한이 필요하다.
배치파일을 마우스 오른쪽 버튼 → **관리자 권한으로 실행**하면 된다. 이때 작업 폴더가 `C:\Windows\System32`로 바뀌므로, 맨 앞에 `cd /d "%~dp0"`을 넣어두는 것이 안전하다.

## 주의할 점

- 배치파일은 **더블클릭 한 번으로 아무 명령이나 실행**할 수 있다. 출처를 모르는 `.bat`은 메모장으로 열어 내용을 먼저 확인하자.
- `del`, `rmdir /s /q`처럼 지우는 명령은 휴지통을 거치지 않는다. 변수가 비어 있으면 엉뚱한 곳을 지울 수 있으니 `if exist`로 먼저 확인하는 것이 좋다.
