## CSS란

**CSS(Cascading Style Sheets)**는 웹 페이지의 **모양과 배치**를 정하는 언어다.
1994년 하콘 비움 리(Håkon Wium Lie)가 제안했고, 1996년 W3C 표준이 되었다.

웹 페이지를 이루는 세 가지 중 **옷**에 해당한다. [[html|HTML]]이 내용을 담고, CSS가 색, 글꼴, 간격, 배치를 정한다.

## 왜 따로 나뉘었나

CSS가 나오기 전에는 글자 색이나 크기를 HTML 태그 안에 직접 적었다. 그러면 디자인을 바꿀 때 모든 페이지를 하나하나 고쳐야 한다.
CSS는 **내용(HTML)과 디자인(CSS)을 분리**해서, 스타일 파일 하나만 고치면 사이트 전체의 모양이 바뀌도록 했다.

## 이름의 뜻: Cascading

**Cascading**은 "폭포처럼 흘러내린다"는 뜻이다.
한 요소에 여러 스타일 규칙이 겹칠 때, 정해진 순서(우선순위)에 따라 어떤 규칙을 적용할지 결정하는 방식을 가리킨다.
스타일이 생각대로 안 바뀔 때는 대부분 다른 규칙이 우선순위에서 이기고 있는 경우다.

## 기본 구조

CSS는 **어떤 요소에(선택자)** **무엇을 어떻게(속성과 값)** 적용할지 적는 규칙의 모음이다.
자세한 문법은 하위 문서로 정리할 예정이다.

## 할 수 있는 것

| 분야 | 예 |
| --- | --- |
| 꾸미기 | 색, 글꼴, 테두리, 그림자 |
| 배치 | Flexbox, Grid로 요소를 가로·세로로 정렬 |
| 반응형 | 화면 크기에 따라 다른 배치 (미디어 쿼리) |
| 테마 | 변수로 색을 모아두고 다크 모드·라이트 모드 전환 |
| 움직임 | 전환(transition), 애니메이션 |

이 사이트의 다크 테마와 라이트 테마 전환도 CSS 변수로 색을 바꾸는 방식이다.

## 버전

예전에는 CSS2, CSS3처럼 불렀지만, 지금은 기능별 **모듈**(Flexbox, Grid, 색상 등)이 각자 따로 발전한다.
"CSS3"는 하나의 버전이라기보다 현대 CSS를 통틀어 부르는 말로 보면 된다.
