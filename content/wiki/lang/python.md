## Python이란

**Python(파이썬)**은 귀도 반 로섬(Guido van Rossum)이 만들어 1991년에 처음 공개한 프로그래밍 언어다.
이름은 뱀이 아니라 영국 코미디 프로그램 *몬티 파이썬(Monty Python)*에서 따왔다고 한다.

"코드는 쓰는 것보다 읽는 일이 더 많다"는 생각을 바탕으로, **사람이 읽기 쉬운 코드**를 중요하게 여긴다.
그래서 처음 배우는 언어로도 많이 쓰이고, 실무에서도 빠르게 만들어 보는 용도로 널리 쓰인다.

## 특징

| 특징 | 설명 |
| --- | --- |
| **읽기 쉬운 문법** | 중괄호 대신 **들여쓰기**로 코드 블록을 나눈다. 들여쓰기가 곧 문법이라서 코드 모양이 자연스럽게 정돈된다 |
| **인터프리터 언어** | 컴파일 과정 없이 바로 실행해볼 수 있다. 대화형 모드(REPL)에서 한 줄씩 결과를 확인할 수도 있다 |
| **동적 타입** | 변수의 자료형을 미리 적지 않아도 된다. 실행할 때 값에 따라 정해진다 |
| **풍부한 표준 라이브러리** | 파일, JSON, 날짜, 웹 요청, SQLite 등 기본 기능이 처음부터 들어 있다("배터리 포함") |
| **거대한 패키지 생태계** | PyPI(Python Package Index)에 공개된 패키지를 `pip`로 바로 설치해서 쓸 수 있다 |

### 단점도 있다

- **속도:** C, Java 같은 언어보다 실행이 느린 편이다. 그래서 계산이 많은 라이브러리(NumPy 등)는 내부를 C로 만들어 두고 Python에서는 불러다 쓴다.
- **실행해 봐야 아는 오류:** 동적 타입이라 자료형 실수가 실행 중에 드러난다. 타입 힌트와 검사 도구(Pylance, mypy 등)로 보완할 수 있다.

## 어떻게 실행되나

우리가 보통 쓰는 Python은 **CPython**이라는 공식 구현이다.
`.py` 파일을 실행하면 먼저 **바이트코드**로 바꾸고, 이것을 Python 가상 머신이 한 줄씩 실행한다.
실행하고 나면 생기는 `__pycache__` 폴더가 바로 이 바이트코드를 저장해 둔 곳이다.

## 버전

- 지금 쓰는 것은 **Python 3**이다. Python 2는 2020년 1월에 지원이 끝났으므로, 오래된 자료에서 `print "hello"`처럼 괄호 없는 코드를 보면 Python 2 코드라고 생각하면 된다.
- Python 3 안에서도 매년 새 버전(3.12, 3.13 …)이 나온다. 라이브러리마다 지원하는 버전이 다를 수 있으니, 프로젝트마다 쓰는 버전을 정해두는 것이 좋다.
