## JavaScript란

**JavaScript(자바스크립트, JS)**는 웹 페이지에 **동작**을 더하는 프로그래밍 언어다.
1995년 넷스케이프의 브렌던 아이크(Brendan Eich)가 만들었다. 처음 버전은 약 10일 만에 만들었다고 알려져 있다.

웹 페이지를 이루는 세 가지 중 **근육**에 해당한다. [[html|HTML]]이 내용, [[css|CSS]]가 모양을 맡는다면, JavaScript는 버튼을 눌렀을 때 일어나는 일, 화면 갱신, 서버와의 통신을 맡는다.

## Java와는 관계없다

이름이 비슷하지만 **Java와는 다른 언어**다.
당시 인기 있던 Java의 이름을 마케팅에 활용하려고 붙인 이름이라서, 문법 일부가 비슷해 보일 뿐 설계와 동작 방식은 다르다.

## ECMAScript

JavaScript의 표준 이름은 **ECMAScript**다.
2015년에 나온 **ES2015(ES6)**에서 큰 변화가 있었고, 이후로는 매년 새 기능이 조금씩 추가된다.
오래된 자료와 최신 자료의 코드 모양이 많이 다르다면 대부분 이 차이다.

## 특징

| 특징 | 설명 |
| --- | --- |
| **브라우저에서 실행** | 모든 웹 브라우저에 JavaScript 엔진이 들어 있어서 설치 없이 실행된다 (크롬은 V8) |
| **동적 타입** | 변수의 자료형을 미리 적지 않는다. [[python|Python]]과 비슷하다 |
| **이벤트 중심** | 클릭, 입력, 스크롤 같은 사건이 일어나면 실행할 코드를 걸어두는 방식으로 동작한다 |
| **비동기 처리** | 하나의 흐름(싱글 스레드)으로 돌지만, 서버 응답을 기다리는 동안 화면이 멈추지 않도록 기다리는 작업을 뒤로 미뤄둔다 |

## 브라우저 밖에서도

- **Node.js:** 크롬의 V8 엔진을 브라우저 밖으로 꺼내서, JavaScript로 서버나 명령줄 도구를 만들 수 있게 했다. 패키지는 **npm**으로 설치한다.
- **TypeScript:** JavaScript에 자료형을 적을 수 있게 만든 언어다. 실행 전에 자료형 실수를 잡을 수 있어서 큰 프로젝트에서 많이 쓴다.
- 이 사이트를 만드는 Astro도 Node.js 위에서 동작한다.

## 브라우저에서 확인하기

[[크롬-개발자-도구]]의 Console 탭에서 JavaScript를 바로 실행해볼 수 있고, 페이지에서 난 오류도 여기에 나온다.
Network 탭에서는 JavaScript가 서버로 보낸 요청과 응답을 볼 수 있다. ([[api-역공학]])

## 주의할 점

- 브라우저에서 도는 JavaScript는 **사용자가 전부 볼 수 있고 바꿀 수도 있다.** API 키를 넣거나, 권한 검사를 JavaScript에만 맡기면 안 된다. ([[웹-정찰]], [[idor]])
- 외부에서 받은 글을 HTML로 바로 넣으면 XSS가 생길 수 있다. ([[owasp-top-10#a05-injection-인젝션|OWASP Top 10 A05]])
