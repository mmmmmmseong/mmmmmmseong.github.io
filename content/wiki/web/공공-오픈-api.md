## 오픈 API란

**오픈 API**는 기관이나 회사가 **외부 개발자가 쓰라고 공식으로 공개한** 데이터 창구다. 요청 방법과 응답 형식이 문서로 정리되어 있고, 인증키를 받아 쓴다.

공공기관의 오픈 API는 대부분 무료다. 정부가 가진 데이터를 국민이 활용할 수 있게 공개하는 것이기 때문이다.

| 사이트 | 데이터 |
| --- | --- |
| **공공데이터포털** (data.go.kr) | 대부분의 정부·공공기관 데이터. 날씨, 대중교통, 미세먼지, 부동산 등 |
| **NEIS 교육정보 개방 포털** (open.neis.go.kr) | 학교 정보, 시간표, 급식 식단, 학사일정 |
| **서울 열린데이터광장** 등 지자체 포털 | 지역 데이터. 지하철 실시간 위치, 공공 자전거 등 |

## 공식 API와 비공식 API

[[api-역공학|역공학]]으로 알아낸 비공식 API와 비교하면 차이가 분명하다.

| | 공식 오픈 API | 비공식 API (역공학) |
| --- | --- | --- |
| 사용 허락 | 처음부터 쓰라고 공개했다 | 허락받지 않았다. 약관에 따라 문제가 될 수 있다 |
| 문서 | 요청 인자, 응답 형식, 오류 코드가 공개되어 있다 | 직접 추리해야 한다 |
| 안정성 | 바뀌면 공지한다 | **예고 없이 바뀌거나 막힌다** |
| 인증 | 개인 인증키, 사용량 관리 | 없거나, 우회해야 한다 |
| 데이터 | 공식 명칭, 정해진 범위만 | 화면에 보이는 것은 다 있다 |

스쿨헬퍼는 처음에 컴시간의 비공식 응답을 읽었다. 2026년 11월 컴시간이 요청 토큰과 응답 암호화를 넣어 막자, 우회하지 않고 NEIS 공식 API로 바꿨다. 같은 시간표 데이터인데도 공식 API는 **허락을 받은 길**이라는 점이 결정적이었다.

## 인증키 받기

1. 포털에 회원가입한다.
2. 쓰고 싶은 API의 "인증키 신청"에서 사용 목적을 적는다. 대부분 바로 발급된다.
3. 받은 키를 요청 주소의 인자로 붙인다.

인증키는 **나를 식별하는 값**이다. 다른 사람이 내 키로 요청을 쏟아내면 내 키가 정지될 수 있다.
- 코드에 직접 적지 않는다. 파이썬은 `.env`, Flutter는 빌드할 때 주입한다. → [[env로-api-키-관리]]
- 공개 저장소에 올리지 않는다.
- 다만 **앱에 넣은 키는 결국 앱 안에 들어간다.** 앱을 풀어 보면 꺼낼 수 있으므로 완전한 비밀은 아니다. 공공 API처럼 무료이고 피해가 적은 키는 감수하고, 중요한 키는 서버에 둔다.

## 요청 보내기: NEIS 시간표 예

NEIS의 고등학교 시간표 API(`hisTimetable`)로 2학년 3반의 한 주 시간표를 요청하면 이렇다.

```text
https://open.neis.go.kr/hub/hisTimetable
  ?KEY=<인증키>
  &Type=json
  &pIndex=1
  &pSize=1000
  &ATPT_OFCDC_SC_CODE=E10        시도교육청 코드 (인천)
  &SD_SCHUL_CODE=<학교 코드>
  &GRADE=2
  &CLASS_NM=3
  &TI_FROM_YMD=20261123          시작일
  &TI_TO_YMD=20261127            종료일
```

### 공통 인자

| 인자 | 뜻 |
| --- | --- |
| `KEY` | 인증키. 없으면 **샘플 모드**로 5건만 준다 |
| `Type` | 응답 형식. `json` 또는 `xml` (기본값 xml) |
| `pIndex` | 페이지 번호 |
| `pSize` | 한 페이지의 건수. 최대 1,000 |

### 코드는 다른 API로 찾는다

학교 코드처럼 처음 보는 코드는 보통 **다른 API로 조회**한다. NEIS에서는 학교 기본정보 API(`schoolInfo`)에 학교 이름을 넣으면 교육청 코드와 학교 코드를 알려준다.

```text
https://open.neis.go.kr/hub/schoolInfo?Type=json&ATPT_OFCDC_SC_CODE=E10&SCHUL_NM=남동고
```

## 응답 처리하기

### 정상 응답

```json
{"hisTimetable": [
  {"head": [{"list_total_count": 34},
            {"RESULT": {"CODE": "INFO-000", "MESSAGE": "정상 처리되었습니다."}}]},
  {"row": [
    {"ALL_TI_YMD": "20261123", "GRADE": "2", "CLASS_NM": "3",
     "PERIO": "1", "ITRT_CNTNT": "미적분Ⅰ", "LOAD_DTM": "20261119"}
  ]}
]}
```

- 실제 데이터는 `row` 배열에 들어 있다. `head`에는 전체 건수와 결과 코드가 있다.
- **모든 값이 문자열이다.** 교시(`PERIO`)도 `"1"`이라서, 정렬하거나 비교할 때 숫자로 바꿔야 한다. 문자열로 정렬하면 `"10"`이 `"2"`보다 앞에 온다.

### 데이터가 없거나 오류일 때

이때는 응답 모양 자체가 다르다. `hisTimetable` 없이 `RESULT`만 온다.

```json
{"RESULT": {"CODE": "INFO-200", "MESSAGE": "해당하는 데이터가 없습니다."}}
```

| 코드 | 뜻 | 앱에서 할 일 |
| --- | --- | --- |
| `INFO-000` | 정상 | 데이터 표시 |
| `INFO-200` | 데이터 없음 (방학, 아직 등록 안 된 날짜) | **오류가 아니다.** 빈 시간표를 보여준다 |
| `INFO-300` | 관리자가 인증키 사용을 제한함 | 오류 표시 |
| `ERROR-290` | 인증키가 유효하지 않음 | 키 설정 확인 |
| `ERROR-300` | 필수 값 누락 | 요청 코드 확인 |
| `ERROR-336` | 한 번에 1,000건 넘게 요청함 | 페이지를 나눠 요청 |
| `ERROR-337` | 하루 사용량 초과 | 캐시를 늘리고 요청을 줄인다 |
| `ERROR-500` 등 | 서버 오류 | 잠시 후 다시 시도 |

공공 API는 HTTP 상태 코드가 200이어도 **본문의 결과 코드가 오류**인 경우가 많다. [[http와-https#상태-코드|상태 코드]]만 보고 성공으로 판단하면 안 된다.

스쿨헬퍼는 이렇게 나눴다.

```dart
final result = data['RESULT'];
if (result != null) {
  if (result['CODE'] == 'INFO-200') return [];                 // 데이터 없음 → 빈 시간표
  throw Exception('${result['MESSAGE']} (${result['CODE']})');  // 그 밖은 오류로 표시
}
return data['hisTimetable'][1]['row'];
```

### 페이지 나누기

건수가 `pSize`보다 많으면 `pIndex`를 1, 2, 3으로 올리며 나눠 받는다. `head`의 `list_total_count`로 전체 건수를 알 수 있다.
가능하면 **조건을 좁혀서** 한 페이지에 들어오게 하는 편이 간단하다. 스쿨헬퍼는 학교 전체가 아니라 학급 하나, 두 주 분량만 요청해서 한 번에 받는다.

## 데이터를 직접 확인하기

문서만 믿지 말고 실제 응답을 여러 날짜로 받아 봐야 한다. 스쿨헬퍼에서 직접 확인해서 알게 된 것들이다.

- **학사일정이 수업 대신 들어온다.** 휴업일에는 과목명 자리에 `재량휴업일`, `대수능-휴업일` 같은 이름이 들어온다.
- **토요일 행도 온다.** `토요휴업일`이 들어와서, 월~금만 보여주려면 걸러야 한다.
- **교시 수가 날마다 다르다.** 2교시만 있는 날도 있다.
- **반 번호가 실제 반이 아닌 행이 있다.** 선택과목 이동수업 시간에는 `CLASS_NM`이 이동반 번호이고, 일부 소규모 과목은 반 없이 강의실 번호만 있다.
- **없는 정보도 있다.** NEIS에는 교사 이름과 분반 표시가 없다. 과목명은 줄임말이 아닌 정식 명칭이라 길다.
- **갱신 주기:** 행마다 있는 `LOAD_DTM`(저장된 날짜)을 보면 하루 단위로 갱신된다. 그래서 하루에 한 번만 새로 받도록 [[로컬-캐싱|캐시]]했다.

## 이용할 때 지킬 것

- **출처 표시:** 공공데이터는 대부분 출처만 밝히면 자유롭게 쓸 수 있다. 다만 데이터마다 이용 조건(공공누리 유형 등)이 다를 수 있으니 확인한다.
- **요청을 아낀다:** 하루 사용량 제한이 있는 API가 많다. 같은 데이터를 반복해서 요청하지 않도록 캐시한다.
- **개인정보가 섞이지 않았는지 본다:** 공개 데이터라도 다른 데이터와 합치면 개인을 알아볼 수 있게 되는 경우가 있다.

## NEIS에서 쓸 수 있는 다른 데이터

같은 인증키로 학교 관련 데이터를 더 받을 수 있다. 스쿨헬퍼에 기능을 더할 때 후보가 된다.

| API | 데이터 |
| --- | --- |
| `schoolInfo` | 학교 기본 정보 (코드, 주소, 홈페이지) |
| `mealServiceDietInfo` | 급식 식단 (메뉴, 알레르기 정보, 칼로리) |
| `SchoolSchedule` | 학사일정 (시험, 방학, 행사) |
| `classInfo` | 학년별 학급 목록 |
| `hisTimetable` | 고등학교 시간표 (초·중학교는 `elsTimetable`, `misTimetable`) |
