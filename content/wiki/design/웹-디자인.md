## 웹 디자인이란

이 문서는 [[시각-디자인]]에서 정리한 원칙을 **웹 화면에서 실제로 구현하는 방법**을 모아둔다.
원칙 자체(위계, 4원칙, 게슈탈트, 배색)는 시각 디자인 문서에 있고, 여기서는 [[css|CSS]]로 어떻게 옮기는지에 집중한다.

## 종이와 다른 점

포스터는 한 번 인쇄하면 끝이다. 웹 화면은 **보는 사람마다 다르게** 보인다.

| 달라지는 것 | 예 | 그래서 |
| --- | --- | --- |
| **화면 크기** | 휴대폰 360px부터 모니터 2560px까지 | 고정된 배치 대신 크기에 따라 바뀌는 **반응형**으로 만든다 |
| **사용자 설정** | 브라우저 글자 크기 확대, 다크 모드, 움직임 줄이기 | 사용자의 설정을 덮어쓰지 않고 따른다 |
| **상호작용** | 마우스를 올렸을 때, 누를 때, 키보드로 선택했을 때 | 버튼 하나에도 상태별 모양이 필요하다 |
| **글꼴** | 사용자의 컴퓨터에 그 글꼴이 없을 수 있다 | 웹폰트를 불러오고, 대체 글꼴 순서를 정한다 |
| **보는 방법** | 화면 읽기 프로그램, 키보드만 쓰는 사용자 | 대비, 초점 표시, 색에만 의존하지 않기 같은 **접근성**을 지킨다 |

그래서 웹 디자인은 "한 장의 완성된 그림"보다 **규칙의 묶음**을 만드는 일에 가깝다. 어떤 크기와 설정에서도 그 규칙대로 그려지게 하는 것이다.

## 디자인 토큰

**디자인 토큰**은 색, 글자 크기, 간격, 둥근 모서리 같은 디자인 값을 **이름을 붙여 한곳에 모아둔 것**이다. 웹에서는 보통 CSS 변수(사용자 정의 속성)로 만든다.

```css
:root {
  --accent: #2f4f73;   /* 강조색 */
  --text: #1c222a;     /* 본문 글자 */
  --radius: 10px;      /* 모서리 둥글기 */
}

a { color: var(--accent); }
```

- **반복 원칙이 저절로 지켜진다.** 아무 값이나 쓰지 않고 정해 둔 이름만 쓰기 때문이다.
- **한 번에 바꿀 수 있다.** 강조색을 바꾸고 싶으면 변수 한 줄만 고치면 된다.
- **다크 모드가 쉬워진다.** 변수 값만 바꾸면 사이트 전체의 색이 바뀐다.

색은 `--blue-500`처럼 **생김새**로 짓기보다 `--accent`, `--text`, `--muted`처럼 **역할**로 짓는 편이 좋다. 다크 모드에서 `--blue-500`의 값이 하늘색이 되면 이름과 값이 어긋나기 때문이다.

### 4원칙으로 보면

- **대비:** 문서 제목, 소제목, 본문의 크기와 굵기를 확실히 나눴다. 링크만 강조색을 쓴다.
- **반복:** 모든 문서가 같은 틀(분류 → 제목 → 태그 → 본문 → 연결된 문서)을 쓴다. 태그는 어디서나 같은 둥근 알약 모양이다.
- **정렬:** 본문의 제목, 문단, 표, 코드 블록이 모두 같은 왼쪽 선에 맞춰져 있다.
- **근접:** 소제목은 위 여백이 아래 여백보다 커서 아래 문단에 붙어 보인다.
