## 개요

앱에서 오늘 할 일을 적고, **기존 잠금화면 위에서 잠금을 풀지 않고 체크**하는 개인용 안드로이드 플래너다.
서버 없이 폰 안에서만 동작하고, 플레이스토어 없이 APK로 직접 설치해서 쓴다.

대상 기기는 Galaxy S22 Ultra(One UI 8.0, Android 16)다.

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| **시간표** | 월~일 주간 표. 길게 눌러 끌어서 여러 칸 입력, 요일 복사, 이어지는 일정은 합쳐서 표시 |
| **할 일** | 날짜별 관리. 못 끝낸 일은 버튼 하나로 오늘로 옮긴다 |
| **잠금화면 카드** | 오늘 할 일 체크, 오늘 시간표 보기. 접기/펼치기, 탭 전환 |
| **홈 화면 위젯** | 오늘 할 일 목록, 체크, 추가 버튼 |
| **백업** | 안드로이드 자동 백업, JSON 내보내기/가져오기 |

앱·잠금화면 카드·위젯이 **같은 데이터베이스(Room)**를 쓴다. 잠금화면에서 체크하면 앱과 위젯에 바로 반영된다.

## 핵심 문제: 잠금화면에 무엇을 띄울 수 있나

One UI의 잠금화면은 생각보다 막혀 있었다.

- 잠금화면 위젯 칸은 **삼성 앱 전용**이고, 눌러도 잠금을 푼 뒤에 앱이 열린다.
- Now Bar의 큰 펼침 화면은 **미디어 전용**이다.

그래서 여러 방법을 비교하고 하나를 골랐다.

| 방법 | 결정 | 이유 |
| --- | --- | --- |
| 별도 잠금화면 앱 (`showWhenLocked`) | ❌ | 시계·지문·Now Bar 같은 One UI 잠금화면을 그대로 두고 싶었다 |
| 음악 플레이어로 위장해 Now Bar 사용 | ❌ | 미디어 버튼과 Now Bar가 Spotify와 충돌한다 |
| 루팅·시스템 수정 | ❌ | Knox가 손상된다 |
| **접근성 오버레이** | ✅ | 기존 잠금화면 위에 카드만 얹을 수 있다 |

접근성 서비스(`AccessibilityService`)가 쓸 수 있는 오버레이 창(`TYPE_ACCESSIBILITY_OVERLAY`)으로 카드를 띄운다.
설정에서 접근성 서비스를 끄면 바로 원래 잠금화면으로 돌아가고, 꺼져 있어도 앱과 위젯은 정상 동작한다.

## 언제 카드를 보여줄까

카드는 **잠긴 상태이고 화면이 켜져 있을 때만** 보이고, 전화·알람·알림창·PIN 화면·잠금 해제 중에는 숨긴다.
이걸 판단하려고 앞에 뜬 창이 바뀔 때(창 상태 변경 이벤트)만 받는다.

- **다른 앱이 앞에 왔는지:** 잠금 중에 전화·알람 같은 앱 화면이 뜨면 숨긴다. 그런데 잠금 중에 **삼성 월렛 바**가 계속 창 이벤트(`android.widget.FrameLayout`)를 보내서 카드가 사라지는 문제가 있었다. 그래서 앱 화면(Activity)이 아닌 이런 떠 있는 창은 가리는 앱으로 보지 않게 했다.
- **잠금화면 기본 화면인지:** PIN 화면과 알림창은 시스템 UI 창 이벤트의 **첫 문구**로 구분한다. 기본 잠금화면은 `알림 세부정보`로 시작한다(한국어 One UI 기준).
- **잠금 해제:** 잠금이 풀리는 순간에는 상태를 다시 묻지 않고 바로 카드를 치운다. 이 시점에 시스템이 아직 "잠김"으로 답하는 경우가 있어서다.

## 개인정보 원칙

접근성 서비스는 원래 다른 앱의 화면 내용까지 읽을 수 있는 강한 권한이라, 쓰는 범위를 스스로 제한했다.

- 화면 내용을 읽지 않는다 (`canRetrieveWindowContent="false"`).
- 시스템 UI 창의 **첫 문구만 비교**하고 저장하거나 로그로 남기지 않는다. 뒤 문구에는 알림 내용이 섞일 수 있기 때문이다.
- 받는 이벤트는 창 상태 변경 하나뿐이고, 다른 앱의 내용은 수집하지 않는다.
- 카드에서는 글자를 입력받지 않는다. 입력은 앱에서만 한다.

## 현재 상태

- MVP 기능 코드는 모두 작성했고, 빌드와 단위 테스트(시간표 합치기, 백업)는 통과했다.
- 실제 폰에 설치해 **잠금화면 카드를 테스트하는 중**이다. 잠금화면과 접근성 동작은 빌드 성공만으로는 확인할 수 없어서, 무선 디버깅으로 연결한 실제 폰에서 확인한다.
- 알려진 한계: Now Bar를 펼치는 동작은 창 이벤트가 없어서 감지하지 못한다.

## 다음 목표 (MVP 완료 기준)

- 잠긴 폰에서 화면을 켜면 카드가 보이고 잠금 해제 없이 체크할 수 있다.
- Spotify 재생 중에도 카드와 Now Bar가 서로 방해하지 않는다.
- 재부팅 뒤에도 카드가 다시 나타난다.
- 내보낸 JSON 파일로 데이터를 복원할 수 있다.
