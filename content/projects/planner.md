## 개요

앱에서 시간표와 할 일을 정리하고, **기존 잠금화면 위에서 잠금을 풀지 않고 오늘 할 일을 체크**하는 개인용 안드로이드 플래너다.
서버 없이 폰 안에서만 동작하고, 플레이스토어 없이 APK로 직접 설치한다.

- 대상 기기: Galaxy S22 Ultra (One UI 8.0, Android 16)
- 지원: Android 12 이상 (minSdk 31)
- 버전: 0.1.0, 코드 약 2,500줄

## 전체 구조

할 일을 볼 수 있는 곳이 세 군데다. 세 곳 모두 **같은 데이터베이스를 실시간으로 구독**한다.

```text
                 ┌─ 앱 화면 (Compose) ──────── 시간표 · 할 일 · 설정
TaskRepository ──┼─ 잠금화면 카드 (접근성 서비스) ── 오늘 할 일 · 오늘 시간표
 (Room DB 하나)  └─ 홈 화면 위젯 (Glance) ───── 오늘 할 일
```

- 데이터는 Room의 `Flow`로 흘러가서, 잠금화면에서 체크하면 앱 화면이 바로 바뀐다.
- 쓰기는 화면이 아니라 **앱 전체 수명의 코루틴**에서 실행한다. 체크하자마자 카드가 사라져도(잠금 해제 등) 저장은 끝까지 수행된다.
- 쓰기가 끝날 때마다 위젯도 다시 그리도록 갱신을 요청한다.
- 설정(카드 위치, 시간표 표시 범위, 카드에서 마지막으로 본 탭)은 DataStore에 따로 저장한다.

## 앱 화면

사이드바(서랍 메뉴)로 **시간표 · 할 일 · 설정**을 오간다. 앱을 열면 시간표가 먼저 나온다.

### 시간표

월~일 주간 표에 1시간 단위로 반복 일정(루틴)을 적는다.

- **칸을 누르면** 그 칸, 또는 이어진 일정 묶음 전체를 편집한다.
- **길게 누르고 위아래로 끌면** 같은 요일의 여러 시간을 한 번에 고른다. 손가락이 화면 위아래 끝에 가까울수록 **빠르게 자동 스크롤**되고 선택 범위도 함께 늘어난다.
- 입력 창에서 **요일을 여러 개 고르면** 같은 시간대에 한꺼번에 저장하거나 지운다("평일 모두 선택" 버튼). 이것이 요일 복사 기능이다.
- 같은 요일에 내용이 같은 칸이 이어지면 **하나의 큰 칸으로 합쳐** 보여준다.
- 표시 시간 범위는 설정에서 바꾼다(기본 8시~23시).
- 오늘 요일 열은 강조색 대신 표면 밝기로만 구분한다.

### 할 일

- 날짜별로 할 일을 추가·수정·삭제하고 체크한다.
- 날짜는 좌우 화살표, 날짜를 눌러 달력 선택, **오늘 / 내일** 버튼으로 이동한다.
- 지난 날짜에 못 끝낸 일이 있으면 오늘 화면에 **"못 끝낸 일 N개를 오늘로 옮기기"** 버튼이 뜬다. 누르면 한 번에 오늘로 옮긴다.
- 앱을 켜 둔 채 자정이 지나면, 오늘을 보던 화면은 새 날짜로 따라간다.

### 설정

- 시간표 표시 범위 (범위 슬라이더)
- 잠금화면 카드 켜짐/꺼짐 상태, 접근성 설정·앱 정보로 바로 가는 버튼
- 카드 위치 (화면 위에서부터의 거리)
- 백업 내보내기 / 가져오기

### 홈 화면 위젯

- 오늘 할 일 목록을 보여주고 **위젯에서 바로 체크**할 수 있다.
- **추가** 버튼을 누르면 앱이 열리면서 오늘 날짜로 이동해 입력 창이 바로 뜬다.
- 매일 자정에 WorkManager 작업이 위젯을 새 날짜로 바꾸고, 다음 자정 작업을 다시 예약한다.

## 잠금화면 카드

이 프로젝트의 핵심이다.

### 어떤 방법으로 띄울까

One UI의 잠금화면은 생각보다 막혀 있었다.

- 잠금화면 위젯 칸은 **삼성 앱 전용**이고, 눌러도 잠금을 푼 뒤에 앱이 열린다.
- Now Bar의 큰 펼침 화면은 **미디어 전용**이다.

| 방법 | 결정 | 이유 |
| --- | --- | --- |
| 별도 잠금화면 앱 (`showWhenLocked`) | ❌ | 시계·지문·Now Bar 같은 One UI 잠금화면을 그대로 두고 싶었다 |
| 음악 플레이어로 위장해 Now Bar 사용 | ❌ | 미디어 버튼과 Now Bar가 Spotify와 충돌한다 |
| 루팅·시스템 수정 | ❌ | Knox가 손상된다 |
| **접근성 오버레이** | ✅ | 기존 잠금화면 위에 카드만 얹을 수 있다 |

접근성 서비스(`AccessibilityService`)만 쓸 수 있는 오버레이 창(`TYPE_ACCESSIBILITY_OVERLAY`)으로 카드를 띄운다. 창은 포커스를 받지 않게 설정해서 글자 입력이 생기지 않는다.
접근성 설정에서 서비스를 끄면 즉시 원래 잠금화면으로 돌아가고, 꺼져 있어도 앱과 위젯은 그대로 동작한다.

### 언제 보여줄까

카드는 아래 조건을 **모두** 만족할 때만 보인다.

| 조건 | 판단 방법 |
| --- | --- |
| 잠겨 있다 | `KeyguardManager.isKeyguardLocked` |
| 화면이 켜져 있다 | `PowerManager.isInteractive` |
| 다른 앱이 앞에 없다 | 창 이벤트의 앱 이름과 창 종류 |
| PIN 화면·알림창이 열려 있지 않다 | 시스템 UI 창 이벤트의 첫 문구 |

판단에 쓰는 이벤트는 **창 상태 변경(`TYPE_WINDOW_STATE_CHANGED`) 하나뿐**이다. 실제 폰에서 부딪힌 문제를 하나씩 처리했다.

- **다른 앱이 가렸을 때:** 잠금 중에 전화·알람 같은 앱 화면이 뜨면 숨긴다. 이 앱 자신, 시스템 UI, AOD, 생체 인증 화면, 기본 홈 앱은 가리는 앱으로 보지 않는다.
- **삼성 월렛 바:** 잠금 중에 월렛 바가 `android.widget.FrameLayout` 창 이벤트를 계속 보내서 카드가 사라졌다. 그래서 앱 화면(Activity)이 아닌, 이름이 `android.`로 시작하는 떠 있는 창은 가리는 앱으로 보지 않게 했다.
- **PIN 화면과 알림창:** 시스템 UI 창 이벤트의 **첫 문구**로 구분한다. 기본 잠금화면은 `알림 세부정보`로 시작하고 그 뒤에 시계 등의 문구가 이어진다. 한국어 One UI 기준이다.
- **잠금 해제 순간:** 잠금 해제 신호(`USER_PRESENT`)를 받으면 상태를 다시 묻지 않고 바로 치운다. 이 시점에 시스템이 아직 "잠김"이라고 답하는 경우가 있어서다.
- **신호를 놓쳤을 때:** 카드가 떠 있는 동안 **0.5초마다** 상태를 다시 확인한다. 어떤 이벤트를 놓쳐도 카드가 잠금 해제 후까지 남지 않게 하는 안전장치다.
- **화면이 꺼지면** "가려짐" 상태를 초기화한다. 화면이 켜질 때마다 오늘 날짜와 현재 시각을 새로 읽는다.

### 카드 화면

```text
접힌 상태   ┌──────────────────────────────────┐
            │ 오늘 2/5 · 수학 문제집 3장       ▾ │
            └──────────────────────────────────┘
펼친 상태   ┌──────────────────────────────────┐
            │ [할 일 2/5]  시간표               ▴ │
            ├──────────────────────────────────┤
            │ ☑ 영단어 30개                      │
            │ ☐ 수학 문제집 3장                  │
            │ ...  (5줄 넘으면 스크롤)           │
            └──────────────────────────────────┘
```

- **접힌 상태**는 마지막으로 본 탭의 한 줄 요약이다.
  - 할 일 탭: `오늘 완료/전체 · 다음에 할 일` (다 끝내면 "모두 완료!")
  - 시간표 탭: `지금 또는 다음 일정의 시간 · 제목`
- 위쪽 줄을 누르면 펼쳐지고, 그 자리가 **할 일 / 시간표 탭**으로 바뀐다. 마지막으로 본 탭은 설정에 저장해서 다음에도 그 탭으로 열린다.
- 한 번에 5줄까지 보이고 넘치면 스크롤한다.
- **시간표 탭**은 지금 시간 일정을 굵게, 배경색으로 강조한다. 지난 일정은 흐리게 보이고, 펼치면 지금 일정 위치로 스크롤한다.
- **체크하면** 짧은 진동, 체크 표시가 튀어나오는 애니메이션, 제목 취소선과 색 전환이 함께 일어난다.

### 부드럽게 보이게 하려고 한 것

- **나타날 때**는 위쪽을 기준으로 살짝 커지며 서서히 보이고(0.22초), **사라질 때**는 빠르게 흐려진다(0.1초). 사라지는 중에 다시 보여야 하면 그 상태에서 이어서 나타난다.
- **펼치는 동안 창 크기를 매 프레임 바꾸면 끊겨 보인다.** 그래서 애니메이션 중에는 창 높이를 큰 쪽으로 고정하고, 안쪽 내용만 움직인다.
- **할 일이 바뀌어도 줄 구성이 같으면** 기존 줄의 내용만 바꾼다. 줄을 새로 만들면 체크 애니메이션이 끊기기 때문이다.
- 카드 위치는 설정에서 조절한다. 기본값은 시계와 삼성 위젯 아래, 지문 센서 위(300dp)다.

### 개인정보 원칙

접근성 서비스는 원래 다른 앱의 화면 내용까지 읽을 수 있는 강한 권한이라, 쓰는 범위를 스스로 제한했다.

- 화면 내용을 읽지 않는다 (`canRetrieveWindowContent="false"`).
- 시스템 UI 창의 **첫 문구만 비교**하고 저장하거나 로그로 남기지 않는다. 뒤 문구에는 알림 내용이 섞일 수 있다.
- 받는 이벤트는 창 상태 변경 하나뿐이다. 디버그 빌드에서만 앱 이름과 창 종류를 로그로 남긴다.
- 접근성 설정 화면의 서비스 설명에도 "화면 내용은 읽지 않는다"고 밝혀 두었다.

## 데이터와 백업

### 저장 구조

| 테이블 | 내용 | 키 |
| --- | --- | --- |
| `tasks` | 제목, 날짜, 완료 여부 | 자동 번호 (날짜에 색인) |
| `routines` | 요일, 시작 시각, 제목 | 요일 + 시각 |

- 시간표는 **1시간 칸 단위로 그대로 저장**하고, 이어진 칸을 합치는 것은 화면에 보여줄 때만 한다. 그래서 칸 하나만 고치거나 지워도 저장 구조가 단순하다.
- 폰에 실제 데이터가 있어서, DB 구조를 바꿀 때는 마이그레이션을 추가한다. 시간표 기능을 넣을 때 `routines` 테이블을 만드는 1 → 2 마이그레이션을 넣었다.

### 백업

- **JSON 내보내기/가져오기:** 파일 형식에 버전 번호를 넣었다. 시간표가 없던 버전 1 파일도 읽는다.
- **가져올 때는 파일 전체를 먼저 검증**한다. 버전, 필드, 요일·시각 범위가 맞는지 확인한 뒤 하나의 트랜잭션으로 교체한다. 잘못된 파일이면 기존 데이터는 그대로 남는다.
- 가져오기 전에 "지금 있는 할 일이 모두 지워진다"는 확인 창을 띄운다.
- 안드로이드 자동 백업도 켜 두었다.

## 테스트와 현재 상태

**단위 테스트 8개**

| 대상 | 확인하는 것 |
| --- | --- |
| 시간표 합치기 (3개) | 이어진 같은 일정은 합치고, 사이가 비거나 제목·요일이 다르면 따로 둔다 |
| 백업 (5개) | 내보내고 다시 읽으면 같다, 버전 1 파일을 읽는다, 모르는 버전·잘못된 할 일·범위를 벗어난 시간표는 거부한다 |

**현재 상태**

- MVP 기능 코드는 모두 작성했고, 빌드와 단위 테스트는 통과했다.
- 실제 폰에 설치해 **잠금화면 카드를 테스트하는 중**이다. 잠금화면과 접근성 동작은 빌드 성공만으로는 확인할 수 없어서, 무선 디버깅으로 연결한 실제 폰에서 확인한다.
- 알려진 한계: Now Bar를 펼치는 동작은 창 이벤트가 없어서 감지하지 못한다. 펼친 Now Bar와 카드가 겹칠 수 있다.

**MVP 완료 기준 (남은 확인)**

- 잠긴 폰에서 화면을 켜면 카드가 보이고 잠금 해제 없이 체크할 수 있다.
- 잠금화면에서 체크한 내용이 앱과 위젯에 바로 반영된다.
- Spotify 재생 중에도 카드와 Now Bar가 서로 방해하지 않는다.
- 재부팅 뒤에도 카드가 다시 나타난다.
- 내보낸 JSON 파일로 데이터를 복원할 수 있다.
