## 개요

**배치파일**(`.bat`)은 Windows에서 여러 작업을 한 번에 실행하게 해주는 파일이다. ([[batch|배치파일 문법]])
"프로그램 몇 개를 켜고, 파일을 받아서 풀고, 폴더를 옮긴다" 같은 반복 작업을 더블클릭 한 번으로 끝낼 수 있어서 편하다.

문제는 문법이다. 따옴표를 어디에 붙여야 하는지, `%`가 왜 사라지는지, 경로에 괄호가 있으면 왜 깨지는지 같은 함정이 많다.
batCreat은 **"프로그램 열기", "다운로드하기", "폴더 옮기기" 같은 하고 싶은 일**을 순서대로 쌓기만 하면,
이런 문법 처리는 도구가 알아서 하도록 만든 Windows용 GUI 도구다.

```text
 1.  만약 '바탕화면\AI_Bridge_demo_files' 폴더가 있으면
 2.          배치 끝내기 (남은 단계는 실행 안 함): 이미 준비되어 있어요
 3.  조건 끝
 4.  다운로드: GitHub 저장소 → 다운로드\AI_Bridge.zip (받은 뒤 압축 풀기)
 5.  파일/폴더 이동하기: 다운로드\AI_Bridge → 바탕화면\AI_Bridge_demo_files
 6.  프로그램 열기: chrome.exe
```

### 특징

- **명령어 대신 문장으로:** 할 일을 메뉴에서 고르고 질문에 답하기만 하면 된다.
- **질문형 입력 창:** 단계마다 필요한 칸만 보여주고, 경로는 찾아보기·바로가기·자동완성으로 고른다.
- **조건 분기:** "파일이 있으면 / 없으면", "프로그램이 켜져 있으면" 같은 조건과 "아니면" 분기, 중첩까지 지원한다.
- **다른 PC에서도 동작:** 바탕화면·다운로드 같은 위치는 `%USERPROFILE%\Desktop`처럼 환경변수로 들어간다.
- **안전한 기본값:** 이미 있는 파일은 건드리지 않고, 실패하면 멈추기를 고를 수 있고, 실행 전에 확인을 받는다.
- **가벼움:** Python 기본 라이브러리(Tkinter)만 쓰는 파일 하나(`main.py`)다.

## 화면과 사용 흐름

```text
┌ 파일 메뉴: 새로 만들기 / 열기 / 저장 / 다른 이름으로 저장 / .bat 내보내기 / 끝내기 ┐
│  순서대로 실행할 단계                                  [+ 단계 추가 ▼]          │
│  ┌───────────────────────────────────────────────┐   [ 수정 ] [ 복제 ]         │
│  │ 1.  프로그램 열기: chrome.exe                  │   [ 삭제 ]                  │
│  │ 2.  만약 '바탕화면\작업' 폴더가 없으면 (파란색) │   [ ▲ 위로 ] [ ▼ 아래로 ]   │
│  │ 3.          폴더 만들기: 바탕화면\작업         │                             │
│  │ 4.  조건 끝                          (파란색) │                             │
│  └───────────────────────────────────────────────┘                             │
│  옵션: ☐ 관리자 권한으로 실행  ☑ 진행 상황 표시  ☑ 끝나면 창 유지                │
│  [코드 보기]                              [바로 실행해보기]  [.bat 저장]        │
└────────────────────────────────────────────────────────────────────────────────┘
```

1. **+ 단계 추가**에서 할 일을 고른다. 선택한 줄 **바로 아래**에 들어간다.
2. 뜨는 질문 창에 내용을 채운다.
3. 목록에서 **▲ 위로 / ▼ 아래로**로 순서를 맞춘다. 더블클릭하면 수정할 수 있다.
4. **코드 보기**로 만들어질 코드를 확인하고, **바로 실행해보기**로 실제 동작을 확인한다.
5. **.bat 저장**으로 배치파일을 만든다.
6. 나중에 고칠 수 있도록 **파일 → 저장**으로 **작업 파일**(`.json`)도 남겨둔다. `.bat`만으로는 다시 편집할 수 없다. ([[json]])

창 제목에는 작업 파일 이름이 나오고, 저장하지 않은 변경이 있으면 앞에 `*`가 붙는다.

## 할 수 있는 일

| 단계 | 설명 |
| --- | --- |
| **프로그램 열기** | exe, bat, lnk 등을 실행. "닫힐 때까지 기다리기" 선택 가능 |
| **명령어 실행하기** | 자주 쓰는 명령(IP 확인, DNS 캐시 비우기 등)에서 고르거나 직접 입력 |
| **파일/폴더 열기** | 기본 프로그램이나 탐색기로 열기 |
| **파일/폴더 만들기** | 중간 폴더까지 한 번에 생성. 이미 있으면 건드리지 않음 |
| **웹사이트 열기** | 기본 브라우저로 주소 열기 (`https://`는 자동으로 붙음) |
| **잠시 기다리기** | 1~3600초 대기 |
| **프로그램 닫기** | 실행 중인 프로그램 강제 종료. 실행 중인 목록에서 고를 수 있음 |
| **파일/폴더 이동하기** | 다른 위치·다른 드라이브로 옮기기. 옮기면서 이름 바꾸기 가능 |
| **압축하기 (zip)** | 파일·폴더를 zip으로 묶기 |
| **압축 풀기 (zip)** | zip을 같은 이름의 폴더 등으로 풀기 |
| **다운로드하기** | 주소에서 파일 받기. zip이면 받은 뒤 바로 풀기 가능 |
| **배치 끝내기** | 여기서 멈추고 남은 단계는 실행하지 않음. 메시지 표시 가능 |
| **조건 (만약 ~라면)** | 아래 참고 |

여러 단계에 공통으로 있는 옵션:

- **실패하면 나머지 단계를 멈추기:** 명령어 실행, 이동, 압축, 압축 풀기, 다운로드에 있다. 실패하면 "오류가 발생해서 작업을 멈췄습니다."를 보여주고 끝낸다.
- **같은 이름이 이미 있으면: 덮어쓰기 / 건너뛰기:** 이동, 압축, 압축 풀기에 있다. 폴더를 덮어쓰기로 옮기면 기존 폴더와 **합쳐진다**(기존에만 있던 파일은 유지).

### 다운로드 주소 처리

주소를 붙여넣으면 칸 아래에 **주소 종류와 유의사항**이 바로 표시된다. 인터넷에 접속하지 않고 **주소 모양만 보고** 판단한다.

| 붙여넣은 주소 | 처리 |
| --- | --- |
| 구글 드라이브 파일 공유 링크 | 직접 다운로드 주소로 변환. 주소에 파일 이름이 없어서 저장할 이름은 직접 입력 |
| 구글 문서 / 시트 / 슬라이드 | 실제 파일이 아니라서 **Word / Excel / PowerPoint 파일로 변환**해서 받음. 확장자도 자동으로 맞춤 |
| 구글 드라이브 폴더 | 받을 수 없음 (zip으로 묶어 파일로 공유해야 함) |
| GitHub 저장소 | 기본 브랜치를 zip으로 |
| GitHub 브랜치 (`/tree/브랜치`) | 그 브랜치 전체를 zip으로 |
| GitHub 파일 (`/blob/...`) | 그 파일 하나 |
| 그 외 `http(s)://` 주소 | 주소 그대로 |

공개된 자료만 받을 수 있고, 404 같은 오류는 오류 페이지를 파일로 저장하지 않고 **실패로 처리**한다.

## 조건 (만약 / 아니면 / 끝)

```text
 1.  만약 '다운로드\setup.exe' 파일이 있으면
 2.          프로그램 열기: setup.exe        ← 조건이 맞을 때
 3.  아니면 (조건이 안 맞을 때)
 4.          다운로드: 일반 파일 주소 → ...   ← 조건이 안 맞을 때
 5.  조건 끝
```

| 조건 | 추가로 입력하는 것 |
| --- | --- |
| 파일/폴더가 있으면 / 없으면 | 확인할 대상(**상관없음 · 파일만 · 폴더만**)과 경로 |
| 프로그램이 켜져 있으면 / 꺼져 있으면 | 프로그램 이름 (실행 중에서 고르기 가능) |
| 앞 단계가 성공했으면 / 실패했으면 | 없음. 바로 앞 단계의 결과를 봄 |

- 고른 조건에 필요한 칸만 나타난다.
- 조건용 경로 칸은 지금 없는 경로도 넣을 수 있고, 칸 아래에 "지금 이 PC에는 있어요 (폴더)"처럼 현재 상태를 보여준다.
- 블록 안에 블록을 넣을 수 있고(중첩), 이미 있는 단계는 ▲▼로 블록 안팎을 드나든다.

### 블록이 깨지지 않게 하는 규칙

- **'만약' 줄을 고르면 블록 전체**(만약 ~ 끝)가 한 덩어리로 옮겨지고 복제된다.
- '아니면'·'끝' 줄은 따로 옮기거나 복제할 수 없다.
- '만약' 줄을 지우면 **안의 단계까지 지울지, 조건만 없앨지** 고른다.
- 작업 파일을 열 때 블록의 짝이 맞지 않으면 열지 않고 알려준다.

## 경로 입력 칸

```text
[바탕화면        ▼] [프로|            ] [찾아보기]
                     ├ 프로젝트\
                     └ 프로그램 모음\
＋ 새로 만들어져요    C:\Users\사용자\Desktop\프로젝트\새폴더
```

- **위치 바로가기:** 바탕화면, 문서, 다운로드, 사용자 폴더, Program Files, "이 배치파일이 있는 폴더"를 고르면 `%USERPROFILE%\Desktop`, `%~dp0` 같은 형태로 들어간다. 찾아보기로 고른 실제 경로도 가장 가까운 바로가기 기준으로 자동으로 바뀌어서, **사용자 이름이 다른 PC에서도 그대로 동작**한다.
- **자동완성:** 입력하면 폴더 안의 항목이 목록으로 나온다. `↑↓`로 고르고 `Tab`으로 확정, `Esc`로 닫는다.
- **상태 표시:** ✔ 있음 / ＋ 새로 만들어짐 / ⚠ 찾을 수 없음 을 실제 경로와 함께 보여준다.

## 옵션

| 옵션 | 설명 |
| --- | --- |
| 관리자 권한으로 실행 | 관리자 권한이 아니면 UAC 확인 창을 띄워 다시 실행한다. 작업 폴더는 배치파일이 있는 폴더로 맞춘다 |
| 진행 상황 표시 | `[2/5] 압축하기: ...`처럼 지금 하는 일을 출력한다 |

## 만들어지는 배치파일

아래 단계를 실제로 변환한 결과다. **코드 보기** 버튼으로 언제든 확인할 수 있다.

```text
 1.  만약 '바탕화면\MyTool' 폴더가 있으면
 2.          배치 끝내기: 이미 설치되어 있어요   (아무 키나 누를 때까지 기다리기)
 3.  조건 끝
 4.  다운로드: GitHub 저장소 → 다운로드\MyTool.zip   (받은 뒤 압축 풀기, 실패하면 멈추기)
 5.  파일/폴더 이동하기: 다운로드\MyTool → 바탕화면   (건너뛰기, 실패하면 멈추기)
```

```bat
@echo off

rem [1] 만약 '바탕화면\MyTool' 폴더가 있으면
if not exist "%USERPROFILE%\Desktop\MyTool\" goto :if1_end

rem [2] 배치 끝내기 (남은 단계는 실행 안 함): 이미 설치되어 있어요
echo [1/3] 배치 끝내기 (남은 단계는 실행 안 함): 이미 설치되어 있어요
echo 이미 설치되어 있어요
pause
exit /b 0

rem [3] 조건 끝
:if1_end

rem [4] 다운로드: GitHub 저장소 → 다운로드\MyTool.zip (받은 뒤 압축 풀기)
echo [2/3] 다운로드: GitHub 저장소 → 다운로드\MyTool.zip (받은 뒤 압축 풀기)
"%SystemRoot%\System32\curl.exe" -fL --retry 2 -o "%USERPROFILE%\Downloads\MyTool.zip" "https://github.com/user/MyTool/archive/HEAD.zip" && powershell -NoProfile -Command "$ProgressPreference='SilentlyContinue'; Expand-Archive -LiteralPath '%USERPROFILE%\Downloads\MyTool.zip' -DestinationPath '%USERPROFILE%\Downloads\MyTool' -Force -ErrorAction Stop" || goto :fail

rem [5] 이동: 다운로드\MyTool → 바탕화면\MyTool
echo [3/3] 이동: 다운로드\MyTool → 바탕화면\MyTool
if not exist "%USERPROFILE%\Downloads\MyTool" goto :mv5_missing
if exist "%USERPROFILE%\Desktop\MyTool" goto :mv5_ok
if not exist "%USERPROFILE%\Downloads\MyTool\" goto :mv5_file
robocopy "%USERPROFILE%\Downloads\MyTool" "%USERPROFILE%\Desktop\MyTool" /E /MOVE /IS /IT /R:1 /W:1 /NFL /NDL /NJH /NJS /NP >nul
if errorlevel 8 goto :mv5_fail
goto :mv5_ok
:mv5_file
move /y "%USERPROFILE%\Downloads\MyTool" "%USERPROFILE%\Desktop\MyTool" >nul
if not errorlevel 1 goto :mv5_ok
goto :mv5_fail
:mv5_missing
echo 옮길 파일/폴더를 찾을 수 없어요: 다운로드\MyTool
:mv5_fail
cmd /c exit 1
goto :fail
goto :mv5_end
:mv5_ok
cmd /c exit 0
:mv5_end

goto :end
:fail
echo.
echo 오류가 발생해서 작업을 멈췄습니다.
pause
exit /b 1
:end

echo.
echo 모든 작업이 끝났습니다.
pause
```

각 단계 위에 `rem [번호] 설명` 주석이 붙어 있어 나중에 코드를 읽기 쉽다.
다운로드·압축·압축 풀기·이동은 모두 **끝난 뒤에** 다음 단계로 넘어가고, 바로 넘어가는 것은 열기 단계뿐이다.

## 구현

### 배치 문법의 함정을 대신 처리

| 함정 | 처리 방법 |
| --- | --- |
| `%`가 변수로 해석됨 (URL의 `%20` 등) | `%%`로 바꿔서 넣는다. 단, `%USERPROFILE%` 같은 위치 바로가기는 그대로 살린다 |
| `start "경로"`가 프로그램이 아니라 **창 제목**으로 읽힘 | 항상 `start ""`로 빈 제목을 먼저 넣는다 |
| 경로에 `(1)` 같은 **괄호**가 있으면 괄호 블록이 깨짐 | 조건을 괄호 블록 대신 **`goto` 라벨**로 만든다. 이동처럼 내부에 분기가 필요한 단계는 단계 번호로 라벨을 구분한다(`:mv5_ok`) |
| `echo`로 `&`, `<`, `>` 같은 기호를 출력하면 명령으로 실행됨 | 앞에 `^`를 붙여 이스케이프한다 |
| PATH에 Git의 리눅스용 `find`, 다른 `curl`이 먼저 잡힘 | `%SystemRoot%\System32\` 전체 경로로 Windows 기본 도구를 부른다 |
| `move`는 **다른 드라이브로 폴더를** 옮기지 못함 | 폴더는 `robocopy /MOVE`, 파일은 `move`로 옮긴다. 파일인지 폴더인지는 **실행할 때** 확인한다(앞 단계에서 받은 것일 수도 있어서) |
| `robocopy`는 성공해도 결과 코드가 1~7 | 8 이상만 실패로 보고, 끝나면 `cmd /c exit 0`으로 성공 상태로 맞춘다. 그래야 다음 "앞 단계가 성공했으면" 조건이 제대로 동작한다 |
| `curl`은 404여도 오류 페이지를 파일로 저장함 | `-f`로 실패 처리하고, `&&`로 다운로드가 성공했을 때만 압축을 푼다 |
| PowerShell의 압축 진행률 표시가 느림 | `$ProgressPreference='SilentlyContinue'`로 끈다 |

### 한글 인코딩

**콘솔 기본 코드페이지**(한국어 Windows는 CP949)로 저장하고, 그 코드페이지로 표현할 수 없는 글자가 있을 때만 **UTF-8로 저장하면서 맨 앞에 `chcp 65001`을 넣는다.** ([[문자-인코딩-utf8-cp949]])

### 단계를 표 하나로 정의

모든 단계 종류는 코드의 `STEP_TYPES` 표에 모여 있다. 항목 하나가 **질문 칸 목록, 코드 생성 함수, 설명 함수, (선택) 입력 검사 함수**를 가진다.
질문 칸의 종류(`text`, `choice`, `path`, `url`, `process` 등)만 정해주면 질문 창은 자동으로 만들어진다.

- `show_when`: 다른 칸의 값에 따라 보이거나 숨는다. (예: 조건이 "파일/폴더"일 때만 경로 칸)
- `add_only`: 추가할 때만 보이고 수정 창에서는 숨는다.
- `browse_sets`: 찾아보기에서 파일/폴더를 고르면 다른 칸(파일만/폴더만)을 자동으로 맞춘다.

## 활용 예시

**업무 시작 세팅**

```text
 1.  만약 'chrome.exe' 이(가) 꺼져 있으면
 2.          프로그램 열기: chrome.exe
 3.  조건 끝
 4.  웹사이트 열기: 사내 그룹웨어 주소
 5.  파일/폴더 열기: 바탕화면\오늘 작업
```

**폴더 백업**

```text
 1.  압축하기: 문서\프로젝트 → D:\백업\프로젝트.zip   (덮어쓰기, 실패하면 멈추기)
 2.  만약 앞 단계가 성공했으면
 3.          배치 끝내기: 백업 완료   (아무 키나 누를 때까지 기다리기)
 4.  조건 끝
```

## 알려진 한계

- 아직 **프로토타입**이라, 실제로 쓰기 전에 **바로 실행해보기**로 꼭 확인해야 한다.
- 바로 실행해보기는 임시 폴더에 저장해서 실행하므로, 그때의 "이 배치파일이 있는 폴더"는 임시 폴더다.
- 파일 만들기의 내용 쓰기는 한 줄만 지원한다.
- 압축은 zip만 지원하고, PowerShell을 띄우므로 단계마다 1~2초 걸린다.
- 다운로드는 공개된 자료만 가능하다. 로그인이 필요한 자료나 구글 드라이브 폴더는 받을 수 없고, 구글이 주소 형식을 바꾸면 동작하지 않을 수 있다.
- 바탕화면을 OneDrive로 옮긴 PC에서는 `%USERPROFILE%\Desktop`이 실제 위치와 다를 수 있다.
- "명령어 실행하기"에 직접 입력한 명령은 그대로 들어가고, "프로그램 닫기"는 강제 종료라서 저장하지 않은 작업이 사라질 수 있다.

## 기술 스택

- Python 3 (3.13에서 확인), Tkinter (표준 라이브러리, 추가 설치 없음)
- 대상: Windows 10 (1803 이상) / Windows 11
- 만들어진 배치파일은 Windows 기본 도구만 쓴다: `curl.exe`(다운로드), PowerShell 5.1(압축), `robocopy`, `tasklist`, `find`, `taskkill`
- 파일 하나(`main.py`)로 동작
