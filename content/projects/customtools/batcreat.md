## 개요

**배치파일**(`.bat`)은 Windows에서 여러 작업을 한 번에 실행하게 해주는 파일이다.
"프로그램 몇 개를 켜고, 폴더를 만들고, 명령어를 실행한다" 같은 반복 작업을 더블클릭 한 번으로 끝낼 수 있어서 편하다.

문제는 문법이다. 따옴표를 어디에 붙여야 하는지, `%`가 왜 사라지는지, 경로에 괄호가 있으면 왜 깨지는지 같은 함정이 많다.
batCreat은 **"프로그램 열기", "3초 기다리기", "폴더 만들기" 같은 하고 싶은 일**을 순서대로 쌓기만 하면,
이런 문법 처리는 도구가 알아서 하도록 만든 GUI 도구다.

```text
 1.  프로그램 열기: chrome.exe
 2.  3초 기다리기
 3.  만약 '바탕화면\작업' 이(가) 없으면
 4.          폴더 만들기: 바탕화면\작업
 5.  조건 끝
 6.  명령어 실행: ipconfig /flushdns
```

## 사용 흐름

1. **+ 단계 추가**에서 할 일을 고른다.
2. 뜨는 질문 창에 내용을 채운다. 경로는 위치 바로가기와 자동완성으로 고를 수 있다.
3. 목록에서 **▲ 위로 / ▼ 아래로**로 순서를 맞춘다. 더블클릭하면 수정할 수 있다.
4. **바로 실행해보기**로 확인한 뒤 **.bat 저장**을 누른다.

나중에 다시 고칠 수 있도록 작업 내용은 **작업 파일**(`.json`)로 따로 저장한다. `.bat`만으로는 다시 편집할 수 없다. ([[json]])

## 할 수 있는 일

| 단계 | 설명 |
| --- | --- |
| **프로그램 열기** | exe 등을 실행. "닫힐 때까지 기다리기" 선택 가능 |
| **명령어 실행하기** | 자주 쓰는 명령(IP 확인, DNS 캐시 비우기 등) 목록에서 고르거나 직접 입력. "실패하면 멈추기" 선택 가능 |
| **파일/폴더 열기** | 기본 프로그램이나 탐색기로 열기 |
| **파일/폴더 만들기** | 중간 폴더까지 한 번에 생성. 이미 있으면 건드리지 않음. 파일에 한 줄 내용 쓰기 가능 |
| **웹사이트 열기** | 기본 브라우저로 주소 열기 |
| **잠시 기다리기** | 정해진 초만큼 대기 |
| **프로그램 닫기** | 실행 중인 프로그램 종료. 실행 중인 목록에서 고를 수 있음 |
| **조건 (만약 ~라면)** | 파일/폴더가 있으면·없으면, 프로그램이 켜져 있으면·꺼져 있으면, 앞 단계가 성공했으면·실패했으면 |

조건 블록에는 "아니면" 칸을 붙일 수 있고, 블록 안에 블록을 넣을 수도 있다.
블록이 깨지지 않도록 **'만약' 줄을 옮기거나 지우면 블록 전체가 함께** 움직인다.

### 옵션

- **관리자 권한으로 실행:** 관리자 권한이 아니면 UAC 확인 창을 띄우고 다시 실행한다.
- **진행 상황 표시:** `[1/5] 프로그램 열기: ...`처럼 지금 하는 일을 출력한다.
- **끝나면 창 유지:** 마지막에 `pause`로 결과 창을 남겨둔다.

## 만들어지는 배치파일

위 예시를 실제로 변환하면 이렇게 된다. **코드 보기** 버튼으로 언제든 확인할 수 있다.

```bat
@echo off

rem [1] 프로그램 열기: chrome.exe
echo [1/4] 프로그램 열기: chrome.exe
start "" /d "%ProgramFiles%\Google\Chrome\Application" "%ProgramFiles%\Google\Chrome\Application\chrome.exe"

rem [2] 3초 기다리기
echo [2/4] 3초 기다리기
timeout /t 3 /nobreak >nul

rem [3] 만약 '바탕화면\작업' 이(가) 없으면
if exist "%USERPROFILE%\Desktop\작업" goto :if3_end

rem [4] 폴더 만들기: 바탕화면\작업
echo [3/4] 폴더 만들기: 바탕화면\작업
if not exist "%USERPROFILE%\Desktop\작업\" mkdir "%USERPROFILE%\Desktop\작업"

rem [5] 조건 끝
:if3_end

rem [6] 명령어 실행: ipconfig /flushdns (실패하면 멈춤)
echo [4/4] 명령어 실행: ipconfig /flushdns (실패하면 멈춤)
ipconfig /flushdns
if errorlevel 1 goto :fail

goto :end
:fail
echo.
echo 오류가 발생해서 작업을 멈췄습니다.
pause
exit /b 1
:end

echo.
echo 모든 작업이 끝났습니다.
pause
```

## 구현

### 배치 문법의 함정을 대신 처리

| 함정 | 처리 방법 |
| --- | --- |
| `%`가 변수로 해석됨 (URL의 `%20` 등) | `%%`로 바꿔서 넣는다. 단, `%USERPROFILE%` 같은 위치 바로가기는 그대로 살린다 |
| `start "프로그램 경로"`가 프로그램이 아니라 **창 제목**으로 읽힘 | 항상 `start ""`로 빈 제목을 먼저 넣는다 |
| 프로그램 폴더에서 실행해야 제대로 뜨는 프로그램 | `start /d`로 작업 폴더를 프로그램 폴더로 지정한다 |
| 경로에 `(1)` 같은 **괄호**가 있으면 `if ( ... )` 블록이 깨짐 | 조건을 괄호 블록 대신 **`goto` 라벨**(`:if3_end`)로 만든다 |
| `echo`로 `&`, `<`, `>` 같은 기호(파이프 기호 포함)를 출력하면 명령으로 실행됨 | 앞에 `^`를 붙여 이스케이프한다 |
| 이미 있는 폴더·파일을 다시 만들면 오류나 덮어쓰기 | `if not exist`로 없을 때만 만든다 |
| PATH에 Git의 리눅스용 `find`가 먼저 잡혀 프로그램 확인이 실패 | Windows의 `find.exe`를 전체 경로로 지정한다 |

### 다른 PC에서도 동작하는 경로

바탕화면, 문서, 다운로드, Program Files, "이 배치파일이 있는 폴더" 같은 **위치 바로가기**를 고르면 배치에는 `%USERPROFILE%\Desktop`, `%~dp0` 같은 환경변수 형태로 들어간다.
찾아보기로 고른 실제 경로도 가장 가까운 바로가기 기준으로 자동으로 바뀌어서, 만든 배치파일을 다른 PC로 옮겨도 그대로 동작한다.

경로 입력칸은 입력하는 동안 폴더 안의 항목을 자동완성으로 보여주고, ✔ 있음 / ＋ 새로 만들어짐 / ⚠ 찾을 수 없음 상태를 표시한다.

### 한글 인코딩

배치파일은 저장한 인코딩과 콘솔 코드페이지가 다르면 한글이 깨진다.
그래서 **콘솔 기본 코드페이지(한국어 Windows는 CP949)로 저장**하고, 그 코드페이지로 표현할 수 없는 글자가 있을 때만 **UTF-8로 저장하면서 맨 앞에 `chcp 65001`을 넣는다.** ([[문자-인코딩-utf8-cp949]])

### 단계를 표 하나로 정의

모든 단계 종류는 코드의 `STEP_TYPES` 표에 모여 있다. 항목 하나가 **질문 칸 목록, 코드 생성 함수, 설명 함수**를 가진다.
새 단계를 추가하려면 이 표에 항목 하나만 늘리면, 메뉴와 질문 창은 자동으로 만들어진다.

### 바로 실행해보기

지금까지 쌓은 단계를 임시 폴더에 배치파일로 저장한 뒤 새 콘솔 창에서 실행한다. 실행 전에 한 번 더 묻는다.

## 알려진 한계

- 아직 **프로토타입**이라, 실제로 쓰기 전에 **바로 실행해보기**로 꼭 확인해야 한다.
- 파일 내용 쓰기는 한 줄만 지원한다.
- 바탕화면·문서가 OneDrive로 옮겨진 PC에서는 `%USERPROFILE%\Desktop`이 실제 위치와 다를 수 있다.
- "명령어 실행하기"에 직접 입력한 명령은 그대로 들어가므로, 내용은 사용자가 확인해야 한다.

## 기술 스택

- Python 3 (3.13에서 확인), Tkinter (표준 라이브러리, 추가 설치 없음)
- Windows 전용 (`tasklist`, `cmd`, 콘솔 코드페이지 사용)
- 파일 하나(`main.py`)로 동작
