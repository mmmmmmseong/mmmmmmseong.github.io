**업로드:** 2026.10.28 (GitHub `legacy` [[git-자주-쓰는-명령어#브랜치|브랜치]]에 그대로 보존)

학교 시간표 서비스인 **컴시간(Comci)**의 비공개 데이터를 역공학으로 분석해서, 학년·반별 주간 시간표를 보여주던 첫 버전이다.
2026년 11월 컴시간이 요청 토큰과 응답 암호화를 도입하면서 403으로 막혔고, 이후 [[schoolhelper-v2|v2에서 NEIS 공식 API로 전환]]했다.

## 핵심 구현

1. **로컬 캐싱:** 서버 응답 전체(약 64KB)를 기기에 저장해서 같은 요청을 반복하지 않도록 했다. 학교 서버 부담을 줄이고 화면도 바로 뜬다. → [[로컬-캐싱]]
2. **파싱 알고리즘:** 역공학으로 알아낸 복합 코드(`[과목번호]0[교사번호]`)를 나눠서 실제 과목명과 선생님 이름으로 바꾼다. → [[api-역공학]]
3. **인코딩 자동 감지:** 서버 응답에 따라 UTF-8과 CP949(EUC-KR)를 구분해서 한글이 깨지지 않게 했다. → [[문자-인코딩-utf8-cp949]]
4. **데이터 구조:** `학년 > 반 > 요일 > 교시` 4단계 배열을 Dart 모델 객체로 정리했다.
5. **사용 흐름:** 학년/반 선택 → 역할 선택 → 주간 시간표 확인 순서로 이동한다.

## AI와 협업한 방식

- **직접 한 일:** 컴시간 서버의 요청과 응답을 분석해서 데이터 구조와 파싱 방법을 정리했다.
- **AI가 한 일:** 정리한 내용을 바탕으로 Dart 코드를 작성했다.
- **함께 다듬은 것:** "서버 부하 최소화", "웹 호환", "스타일 분리" 같은 요구사항을 계속 주면서 구조를 고쳐 나갔고, 인코딩 오류나 JSON 잘림 같은 문제를 빌드하면서 바로 고쳤다.

> 교육 목적의 역공학을 바탕으로 만들었고, 과도한 요청을 막기 위해 캐싱을 강화했다.

## 이 버전의 한계

[[schoolhelper-v2|v2]]에서 발견하고 고친 문제들이다.

- 요청 오류를 `null`로 삼켜서([[예외-처리#오류를-삼키면-안-된다|오류 삼키기]]), 컴시간이 막힌 뒤에도 오류 없이 8월 캐시만 보였다.
- 새로고침할 때 캐시를 먼저 지워서, 오프라인이면 시간표가 사라졌다.
- 공지 테이블에 보안 설정([[rls와-접근-제어|RLS]])이 없어 누구나 공지를 쓰고 지울 수 있었고, 누구나 "임원"을 고를 수 있었다.
- 공지 캐시 키가 하나라서 반을 바꿔도 이전 반 공지가 보였다.
- 공지 페이지에 들어가면 앱이 꺼지는 버그가 있었다.
