## 개요

학교 시간표 서비스인 **컴시간(Comci)**의 비공개 데이터를 역공학으로 분석해서, 인천남동고 학생들이 학년·반별 주간 시간표를 편하게 볼 수 있게 만든 Flutter 앱이다.

## 핵심 구현

1. **로컬 캐싱:** 서버 응답 전체(약 64KB)를 기기에 저장해서 같은 요청을 반복하지 않는다. 학교 서버 부담을 줄이고 화면도 바로 뜬다.
2. **파싱 알고리즘:** 역공학으로 알아낸 복합 코드(`[과목번호]0[교사번호]`)를 나눠서 실제 과목명과 선생님 이름으로 바꾼다.
3. **인코딩 자동 감지:** 서버 응답에 따라 UTF-8과 CP949(EUC-KR)를 구분해서 한글이 깨지지 않게 했다.
4. **데이터 구조:** `학년 > 반 > 요일 > 교시` 4단계 배열을 Dart 모델 객체로 정리했다.
5. **사용 흐름:** 학년/반 선택 → 역할 선택 → 주간 시간표 확인 순서로 이동한다.

## AI와 협업한 방식

- **직접 한 일:** 컴시간 서버의 요청과 응답을 분석해서 데이터 구조와 파싱 방법을 정리했다.
- **AI가 한 일:** 정리한 내용을 바탕으로 Dart 코드를 작성했다.
- **함께 다듬은 것:** "서버 부하 최소화", "웹 호환", "스타일 분리" 같은 요구사항을 계속 주면서 구조를 고쳐 나갔고, 인코딩 오류나 JSON 잘림 같은 문제를 빌드하면서 바로 고쳤다.

> 교육 목적의 역공학을 바탕으로 만들었고, 과도한 요청을 막기 위해 캐싱을 강화했다.
