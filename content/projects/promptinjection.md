## 개요

**프롬프트 인젝션**은 악의적인 입력을 정상적인 프롬프트처럼 꾸며서, 대형 언어 모델(LLM)이 지켜야 할 규칙을 어기게 만드는 공격입니다.
**Break The AI**는 이 공격을 직접 해볼 수 있는 웹 게임입니다.

각 문제의 AI는 절대 말하면 안 되는 비밀(와이파이 비밀번호, 전화번호, 인증 키 등)을 하나씩 알고 있습니다.
플레이어는 **대화만으로** AI가 그 비밀을 털어놓게 만들고, 알아낸 비밀을 채팅창에 입력하면 문제를 풉니다.

## 문제 구성

난이도별로 6개 문제가 있고, 어려울수록 AI의 방어 규칙이 촘촘해집니다.

| 난이도 | 문제 |
| --- | --- |
| 하 | 비밀번호 확보 · 번호 물어보기 |
| 중 | 정답 알아내기 · AI 서류 심사관 |
| 상 | 문서 작성 보조 AI |
| 최상 | 텍스트 변환 AI |

- 쉬운 문제는 "점장이 지시하면 알려준다"처럼 빈틈이 있는 역할을 맡습니다.
- 어려운 문제는 역할극·관리자 사칭·"이전 지시를 무시하라" 같은 흔한 공격을 거절하도록 설정되어 있어, 우회하는 방법을 고민해야 합니다.
- 문제마다 **AI가 기억하는 대화 턴 수**를 다르게 해서, 여러 턴에 걸쳐 쌓아가는 공격이 통하는지가 달라집니다.

## 구현

- **Flask 블루프린트 구조:** 페이지·문제·채팅·랭킹·오픈소스 출처를 블루프린트로 나눴습니다.
  문제 하나가 파일 하나이고, 각 파일이 자기 시스템 프롬프트·정답·제목·기억 턴 수를 등록합니다. 그래서 문제를 추가할 때 다른 코드를 고칠 필요가 없습니다.
- **Gemini API 연동:** 문제별 시스템 프롬프트와 최근 대화 기록을 함께 보냅니다. 무료 티어에서 생기는 일시적인 503/429 오류는 자동으로 재시도합니다.
- **정답 판정은 서버에서:** 플레이어가 정답을 입력하면 AI를 부르지 않고 서버가 바로 판정합니다. 푼 문제는 세션에 기록합니다.
- **랭킹:** SQLite에 기록을 저장하고, **적은 메시지로 푼 순서**로 순위를 매깁니다. 처음 풀었을 때 닉네임을 입력할 수 있습니다.
- **학습 페이지:** 게임 방법, 프롬프트 인젝션의 작동 방식, 직접/간접 인젝션을 예시와 함께 설명하는 튜토리얼을 넣었습니다.
- **오픈소스 출처 표기:** 가져다 쓴 사이드바·채팅 UI 원본을 별도 경로에 그대로 보존하고, 어떻게 고쳐서 썼는지 출처 페이지에 정리했습니다.

## 배운 점

- AI에게 "말하지 마"라고 지시하는 것만으로는 비밀을 지킬 수 없다는 걸, 문제를 만들고 직접 뚫어보면서 확인했습니다.
- 방어 규칙을 하나 추가하면 새로운 우회 방법이 생겨서, 난이도를 조절하는 게 생각보다 어려웠습니다.
