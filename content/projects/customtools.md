## 개요

평소에 "이런 게 있으면 편하겠다" 싶은 것을 **직접 만들어서 모아두는 저장소**다.
도구마다 폴더 하나를 쓰고, 각 폴더에 실행 방법과 사용법을 담은 README를 둔다.

도구가 하나씩 늘어날 때마다 아래 **하위 문서**에 도구별로 정리한다.

## 도구 목록

| 도구 | 하는 일 | 언어 | 상태 |
| --- | --- | --- | --- |
| [[batcreat\|batCreat]] | 명령어를 몰라도 단계를 쌓아서 배치파일(`.bat`)을 만드는 GUI 도구. 다운로드·압축·이동·조건 분기·메시지/질문 창 지원 | Python (Tkinter) | 프로토타입 |

## 저장소 구조

```text
customtools/
├─ README.md
└─ batCreat/        ← 도구 하나 = 폴더 하나
    ├─ main.py      ← 실행 진입점 (나머지는 역할별 모듈)
    ├─ README.md    ← 실행 방법, 사용법, 알려진 한계
    └─ CLAUDE.md    ← 파일 구조와 코드 규칙 요약 (AI 코딩 도구용)
```

## 만들 때 정한 것

- **설치 없이 바로 실행:** 가능하면 표준 라이브러리만 써서, 폴더 하나를 받아 바로 실행할 수 있게 만든다.
- **도구마다 독립:** 도구끼리 코드를 공유하지 않는다. 폴더 하나만 복사해 가도 동작해야 한다.
- **한계는 숨기지 않기:** 아직 확인하지 못한 부분과 알려진 한계는 각 README에 적어둔다.
