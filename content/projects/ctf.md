## 개요

**CTF(Capture The Flag)**는 일부러 취약하게 만든 프로그램이나 웹사이트에서 숨겨진 문자열(Flag)을 찾아내는 보안 대회 형식입니다.
이 프로젝트는 가상 회사의 **사내 인트라넷**을 무대로, 여러 취약점을 순서대로 이용해야 깊숙이 들어갈 수 있는 웹 CTF 문제입니다.

## 풀이 흐름

문제는 실제 침투 과정처럼 단계를 밟아 가도록 설계했습니다.

1. **정찰:** `robots.txt`처럼 사이트가 공개해 둔 파일을 살펴 단서를 얻습니다.
2. **숨겨진 페이지 발견:** 얻은 단서로 일반 메뉴에서는 보이지 않는 인트라넷 로그인 창을 찾습니다.
3. **SQL 인젝션:** 로그인 폼의 취약점을 이용해 인증을 우회합니다.
4. **IDOR:** 로그인 후 페이지에서 다른 사용자의 정보에 접근할 수 있는 권한 검증 누락을 이용합니다.

## 구현

- **Flask + SQLite:** 인트라넷은 대시보드, 메신저, 프로필, 프로젝트 페이지로 구성했습니다. 사용자 데이터는 SQLite에 넣어 실제 서비스처럼 보이게 했습니다.
- **의도된 취약점:** 문자열을 그대로 이어 붙인 SQL 쿼리, 소유자를 확인하지 않는 프로필 조회처럼 실제로 자주 나오는 실수를 일부러 넣었습니다.
- **세션으로 진행 상태 관리:** 앞 단계를 풀어야 다음 단계로 넘어가도록 세션에 진행 상태를 저장합니다.

> ⚠️ 학습용으로 일부러 취약하게 만든 코드라 실제 서비스에 쓰면 안 됩니다.

## 배운 점

- 공격자 입장에서 문제를 설계하면서, 각 취약점이 **왜 생기고 어떻게 막는지**(파라미터 바인딩, 접근 권한 검증)를 더 확실히 이해했습니다.
