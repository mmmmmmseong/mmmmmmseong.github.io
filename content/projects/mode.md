## 개요

Minecraft 26.1.2에 **경제 시스템**을 더하는 Fabric 모드다.
기능 명세서의 MVP를 구현하는 것에서 시작해, 0.10.0 버전까지 토지 보호 단계, 새 광물(미스릴), 목화, 클래스, 모험가 레벨을 추가했다.
버전별로 무엇이 바뀌었는지는 아래 **하위 문서**에 정리했다.

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| **상태창** | G 키로 어디서나 연다. 플레이어 정보, 계좌, 클래스, 서 있는 토지 확인·구매 |
| **시장 장부** | 독서대에서 연다. 판매소·거래소·거래 내역·보유 토지 관리 |
| **판매소** | 정해진 가격으로 아이템을 팔아 계좌에 돈을 넣는다. |
| **거래소** | 가상 시장과 사고판다. 시세는 게임 속 하루마다 재고에 따라 바뀐다(재고가 적으면 오르고 많으면 내림, 하루 최대 ±10%). |
| **주민 주화 거래** | 주민과 모드 전용 주화로 거래한다. |
| **토지** | 토지를 사서 증서를 받고, 0~4단계로 업그레이드해 보호 범위를 넓힌다. 신뢰하는 플레이어를 등록할 수 있다. 보유한 토지는 시장 장부에서 한 번에 관리한다. |
| **장비 강화** | 대장장이 작업대에서 계좌 잔액과 재료를 써서 장비를 강화한다. |
| **미스릴** | 다이아몬드와 네더라이트 사이 성능의 새 광물과 장비. 풀세트를 입으면 이동 속도가 오른다. |
| **목화** | 경작지에 심는 작물. 수확한 솜은 흰색 양털 대신 쓸 수 있다. |
| **클래스** | 조건을 달성하면 해금되는 클래스. 상태창에서 패시브와 선택형을 장착한다. 러너 계열은 누적 거리에 따라 단계가 오른다. |
| **모험가 레벨** | 바닐라 경험치와 별개인 최대 50레벨. 발전과제, 몬스터 처치, 판매 등으로 경험치를 얻는다. |

## 구현

- **서버가 모든 판정:** 화면은 표시만 하고 모든 거래는 서버에서 처리한다. 모드가 없는 클라이언트로 접속하면 상자형 메뉴가 대신 열린다.
- **데이터 안전:** 월드 데이터는 원자적으로 저장하고 백업을 남긴다. 데이터 형식이 바뀌면 이전 월드를 자동으로 변환(마이그레이션)한다.
- **설정 파일:** 모든 수치를 설정 파일로 뺐다. 잘못된 값은 빌드할 때 테스트가 잡아낸다.
- **테스트:** JUnit 단위 테스트와, 실제 서버를 띄워 확인하는 Fabric GameTest 통합 테스트를 갖췄다. 클라이언트 테스트로 장부 화면을 실제로 열어 스크린샷도 찍는다.
- **텍스처:** 미스릴 텍스처는 그림 파일을 넣지 않고, 게임의 바닐라 텍스처를 불러올 때 미스릴 색으로 다시 칠한다. 그래서 리소스팩을 바꾸면 미스릴 모양도 따라 바뀐다.
