## 0.3.0

- **연성:** 최대 강화한 장비 전용. 장비 종류별 특성을 [각인]으로 새기고 특성마다 따로 강화한다(최대 Lv 3, 장비당 2개). 연성된 장비는 이름이 보라색이다.

  | 장비 | 특성 |
  | --- | --- |
  | 무기 | 흡혈 · 방어력 파쇄 · 처형 |
  | 방어구 | 수호 · 은신 · 활력 |
  | 도구 | 풍작 · 통찰 |
  | 활·쇠뇌·방패·낚싯대 | 보존 · 날렵 |

- 강화 화면에 연성 탭 추가. 강화 성공은 모루 소리, 연성 성공은 인챈트 소리
- 주화 최대 묶음 64 → **50**

## 0.3.1

- **연성 비용을 주화만으로 변경:** 희귀 재료를 없애고, 대신 같은 장비에 연성할 때마다 비용이 2배가 된다(5,000 → 10,000 → … → 160,000).

## 0.3.2

- 무기 특성 발동 파티클(흡혈 핏방울, 방어력 파쇄 파편, 처형 표식)
- 처형 최대 레벨: 체력 5% 미만 대상을 즉시 처형
